# 官网首屏重置提醒体验 — 2026-10-28

## 用户反馈与本次调整

上次官网更新虽然补齐了重置功能段落，hero 仍以额度图表为主，没有传达收到提醒的体验。本次将重置提醒作为中英文首屏默认交互演示，保留「额度与任务」切换：

- 进入页面后，一条明确标注为示例的公开重置消息到达，菜单栏橙色铃铛闪烁，出现应用通知样式的横幅。
- 查看消息只聚焦收件箱，不算已读；关闭横幅保留未读和铃铛；明确确认后停止提醒，恢复额度图标，最新线索继续可见。
- 可重新体验通知、暂停动画；系统减少动态效果时保持静态提示。离开可见区域或切换后台时暂停铃铛动画。
- 原生应用实际每五分钟重复通知，网页使用一次到达＋手动重播，不使用加速倒计时冒充真实通知节奏。
- 演示完全在网页内运行，不调用通知权限、声音、真实 feed 或账号接口。公开重置消息不证明个人账号已经重置；该提醒特性标注为 macOS 能力。
- 关闭或确认横幅时收件箱位置保持不变，手机端使用纵向通知／收件箱布局。

官网影响：需要更新并部署。Mac 仍为 v1.39.0，Windows 仍为 v1.38.6-beta.1；此次为官网体验迭代，不重新构建或发布客户端。

- 网站语法、143 项测试、Pages 构建及双平台发布门禁通过。新增 reset-demo.js 只读静态资源已纳入 Worker 公共资源白名单与 CSP/HEAD 验证。

- 中英文各 375／768／1440px 六组视口均无页面横向溢出；减少动态效果下铃铛和横幅动画均为 none。
