# AI Quota Bar 当前产品规格

更新时间：2026-09-11，对应 v1.15.0。

## 产品目标

AI Quota Bar 是一个 macOS 14+ 菜单栏应用，用于集中查看 AI 编程套餐额度、判断当前消耗节奏、观察 Codex 任务与 OpenAI 网络状态，并在长任务期间按需阻止 Mac 睡眠。

应用以 `LSUIElement` 运行，不显示 Dock 图标。左键打开配额菜单，右键打开任务保护与 Clash/Mihomo 控制中心。

## 配额提供商

应用可同时启用多个提供商：

| 提供商 | 凭据来源 | 主要额度 |
| --- | --- | --- |
| Codex | Codex CLI OAuth、本机 CLI 数据或浏览器会话，由 CodexBarCore 读取 | 5 小时、Weekly，支持多个账户 |
| Kimi | 已登录的 Kimi Code CLI `/status`，或 Keychain 中的 API Key | 5 小时、7 天 |
| GLM | Coding Plan API Key，或用量页面 `quota/limit` 请求的 cURL | 5 小时和周积分；兼容旧 Tokens、MCP/Search |
| MiniMax | Keychain 中的 Coding Plan bearer token | 模型当前周期与周额度 |

每个提供商可单独暂停。暂停不会删除凭据，但会停止刷新、隐藏菜单数据，并排除阈值提醒和任务保护判断；恢复后立即刷新。

## 配额展示与历史

- 启动时默认自动刷新，常规默认间隔为 600 秒，也支持手动刷新。
- 服务端周期结束后延迟 15 秒做一次对齐刷新，避免在重置边界读取旧数据。
- 同一时刻的重复刷新请求会在当前请求结束后补跑一次。
- 每个账户、模型独立保存本机历史，用剩余百分比绘制面积图或进度条。
- 图表模式可按模型设为自动、面积图或进度条；自动模式优先为适合的短周期选择曲线。
- 图表显示重置时间、近期变化和按历史窗口计算的额度盈余或透支预测。
- 可隐藏左键菜单中的账户或模型；菜单栏可固定提供商，或自动选择最需要关注的数据。
- 菜单栏支持详细文字和紧凑圆环。圆环可选择额度周期与节奏表达方式，并在 Codex/Kimi 活跃时显示任务能量流。
- Ring 的显示方式（常驻显示/工作感知）与服务商多选分开，支持 Codex、Kimi、MiniMax、GLM 自由组合。关闭的服务商从选项及全选中排除；保留至少一家已启用的选择。
- MiniMax/GLM 不依赖任务检测，选中后在工作感知中也常驻显示额度；GLM 优先使用 5 小时窗口。耗尽额度仍显示 0% 环，缺少数据时显示状态占位。

## 提醒

- 用户可启用剩余额度阈值提醒并设置百分比。
- 低于阈值时显示右下角警告面板。
- 提供商请求错误会保留最后一次有效数据，并显示错误状态。

## Codex 与 Kimi 活跃检测

- Codex 使用随应用安装的生命周期 Hook 和本机状态检测；支持并发任务计数。
- Kimi 使用本机进程与会话活动检测。
- 活跃检测只读取本机状态，不需要上传提示词或任务内容。

## 睡眠保护

- 仅在受支持的 AI 任务活跃时申请显示器、屏保和系统空闲睡眠保护，最后一个任务结束后立即释放。
- 可选的合盖模式由特权辅助程序管理，默认关闭，并需要管理员授权。
- 合盖租约每 30 秒续期；任务结束、心跳丢失、低电量、严重温度压力、用户关闭或最长 12 小时到期时恢复系统睡眠设置。
- 应用升级改变辅助程序指纹时，可能需要重新授权安装辅助程序。

## Clash/Mihomo 网络工具

- 只连接 `127.0.0.1`、`localhost` 或 `::1` 上的 external controller。
- 显示 OpenAI/ChatGPT 活跃连接、上下行速率、连接持续时间和最近 60 分钟历史。
- 可按名称、国家/地区和正则表达式筛选策略节点，测试延迟并手动切换。
- 自动恢复仅在 `openai.com` 和 `chatgpt.com` 连续两轮同时失败后尝试筛选范围内的可用线路，恢复后停止并通知用户。
- 连接观察为只读；只有明确的线路切换操作会修改 Clash/Mihomo 当前选择。

## Mobile Dashboard

- 在本地网络提供只读网页和 PWA，显示配额、任务、线路、连接与睡眠保护状态。
- 可选择一至两个配额模型，支持自动、浅色、深色外观和 OLED 位移保护。
- 活动背景支持颗粒数字雨、点阵波浪和可配置字段的任务遥测弹幕。
- 可选手动配对：五分钟短码换取可撤销的安装凭证，凭据不会保存在 URL 中。
- 账户名默认隐藏；任务进展文字仅在手动配对且用户另行启用共享后提供。
- 实验性媒体可帮助手机保持唤醒，但浏览器和系统省电策略仍可覆盖。

## 云同步

- 默认关闭，启用后使用内置 Cloudflare Worker + D1 服务同步精简额度快照。
- 同步模型额度、账户标签、采样时间和重置时间，不同步任何提供商凭据。
- 用户可选择 7、14、30、60、90 或 180 天保留期，并分别控制当前窗口、短周期和周周期的纯云端数据可见时长。
- 设置中可查看本地数据报告、D1 用量、远端账户，删除单个账户或清除本机/远端历史。
- 客户端对临时错误重试；认证、请求错误和明确的 D1 每日额度耗尽不会在同一轮无效重试。

## 数据与安全边界

- MiniMax、GLM 和可选 Kimi API Key 保存在 macOS Keychain。
- Codex 与 Kimi CLI 凭据继续由各自 CLI 或 CodexBarCore 管理。
- 应用偏好保存在 UserDefaults；配额历史保存在应用支持目录。
- Mobile Dashboard 仅绑定本地网络，敏感遥测默认不共享。
- 云同步只传输额度元数据与账户标签。
- 合盖系统修改由签名校验、管理员授权、心跳租约和安全阈值共同约束。

## 设置结构

设置窗口包含七个标签页：General、Display、Usage、Sync、Mobile、Providers 和 About。

- Display（显示）：以供应商/账号分组的一张模型表，同时设置左键菜单显隐、手机看板选择和额度图表样式。账号行提供菜单总开关，保留模型级选择；菜单全部显示只恢复菜单显隐，不改变手机选择和图表样式。
- 手机看板仍要求 1–2 项；暂不可用的已选模型单列保留，恢复后回到原模型行。Mobile 页提供已选数量和跳转至 Display 的入口，不重复列举模型。
- 显示调整沿用原有偏好存储和后台更新机制，不影响采集、历史、告警、同步，也不重置已保存选择。

## 构建与发布

- Swift Package Manager，Swift tools 5.9，macOS 14 SDK。
- 本仓库依赖同级目录中的 CodexBar checkout。
- `make build` 构建 release 二进制；`make app` 组装应用；`make install` 安装并重启；`make package` 生成 DMG。
- 公开 Apple Silicon DMG 使用 ad-hoc runtime 签名，当前未经过 Apple 公证。
