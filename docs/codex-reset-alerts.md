# Codex 重置提醒使用说明

适用 macOS v1.39.3。Windows v1.38.6-beta.1 尚未接入此功能。

应用从 codex-reset.com 与 codex-resets.com 的公开消息中提取重置线索、预告、已报告重置和 Banked 消息。来源是第三方观察与公告聚合，**不是对你的个人账号是否已重置的确认**。每条消息保留来源和原文链接；两个站点对同一事件可能给出不同时间或状态，因此不做跨站合并。

## 提醒外观

macOS v1.39.1保留全部额度圆环，Codex 上方 C 改为常亮黄点，只有 Codex 图标单元每 0.75 秒在黄色和正常配色之间切换，额度弧线与趋势/节奏图形保留并随数据更新；其他供应商不闪。系统开启「减少动态效果」时黄色常亮。提醒期间暂停任务波纹动画，确认全部已读后恢复原显示模式与动画。若当前选择没有 Codex，临时追加 Codex 单元以定位提醒。Dim 标记仍独立常亮。

应用支持显式启动参数 `--test-reset-alert`，用于预览真实菜单栏闪烁和系统通知路径。先退出应用，再运行 `open /Applications/AIQuotaBar.app --args --test-reset-alert`。测试条目标注「本机测试」，不会写入存储或替代真实消息，确认已读或重启会移除；真实未读消息仍需分别确认。

## 提醒和确认

- 有未读消息时保留额度圆环，以黄点定位 Codex，仅其单元每 0.75 秒在黄色与正常配色间交替；开启系统「减少动态效果」时黄色常亮。任务波纹暂停，确认全部消息后恢复。
- 新消息尝试发送系统通知，仍有未读时每五分钟重复。通知使用同一个汇总位置，不持续堆叠。
- 通知展示取决于系统权限、专注模式和通知设置。没有通知权限时，菜单提供设置入口，菜单栏提醒继续。
- 在左键菜单点击单条勾选或头部「全部已读」，或者使用通知的明确确认按钮，才会结束对应版本的提醒。菜单内确认会保持面板打开。
- 打开菜单、点原文、点通知正文或关闭通知都不会自动已读。原文按钮会先关闭菜单面板再打开浏览器。
- 同一消息升级为确认、内容或预告时间改变时，会生成新未读版本。旧通知的确认按钮不会清掉之后新增或升级的版本。

## 历史、刷新与断网

头部时钟按钮始终可用，展开最近 24 小时消息；未读计数、常驻线索和时钟历史都使用同一窗口。更早的消息仍在本机归档 30 天用于修订去重，只是不再出现在界面里。最新一条明确的重置预告、已报告重置或 Banked 消息即使已读也会常驻，直到更新的明确消息替代；推测线索不作为这条常驻消息。已读后的常驻展示不会重新触发通知。

v1.39.3 起每条消息提供「消除」按钮：立即从面板移除，同一修订版本不会在下次轮询后重新出现；更新的修订仍按新消息正常提醒。消除不会影响其他消息的未读状态。

应用启动后每分钟独立检查三个公开 feed，唤醒后立即检查，失败源退避至少五分钟，不清空本地未读。首次接入一个来源时，24 小时前的历史只作为已见基线；近 24 小时消息会提醒，之后新补发的公告按新消息处理。历史 API 每次最多读取最新 100 条，因此离线很久时无法保证补全站点全部历史。

未读、已读版本和来源初始化状态保存在本机 UserDefaults，重启后恢复。来源删除消息不会自动使本机消息已读。公开抓取不发送 Codex 凭据或个人额度。

## Dim 状态同时显示

「暂时离开」Dim 开启时，菜单栏追加常亮的屏幕＋月亮标记，额度显示和重置圆环提醒期间均可辨认。该标记表示调暗已开启，没有进度含义；关闭或恢复 Dim 后消失。
