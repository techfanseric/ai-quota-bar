## 验证与交付闭环

本轮文档和官网内容同步不是重新发布 Windows 二进制。Windows 543 项测试记录属于 2026-10-24 的既有发行验证，本机 Mac 的检查不能替代 Windows 高 DPI/多显示器目视验收。性能仍不承诺空闲 CPU 低于 1%。

截至文档复核，本次主流程已报告 Mac 完整测试 **742 项、4 项跳过、零失败**，定向测试 **69 项通过**。生产基线由实际浏览器与部署配置核对取得；生产账号 token 已在本机找到并通过 API 访问核验，本轮不再把“缺凭据”当作当前阻塞。

发布主流程继续负责记录：网站语法/测试/版本门禁、Pages 构建、Mac 打包与校验、提交与标签、GitHub 下载回验，以及生产 `/`、`/en/`、`/changelog`、`/en/changelog`、下载链接和更新接口核验。生产核验须保留实际版本、Windows beta 状态、部署 URL/id 和结果，见 [v1.39.0 发布清单](releases/v1.39.0-checklist.md)。

持续规则见 [AGENTS.md](../AGENTS.md)：凡是公开功能或版本改变，每次推送都必须评估官网；涉及则同步与部署，失败就明确 pending 原因。不能仅修正文案和生成 `dist-pages/` 后宣称线上已更新。
