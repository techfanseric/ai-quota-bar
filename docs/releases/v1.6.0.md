# AI Quota Bar v1.6.0

v1.6.0 的重点，是让长时间使用 Codex 和 ChatGPT 变得更省心：任务运行时不再担心 Mac 意外睡眠，连接变慢或中断时也不用来回切换 Clash 查原因。

## 让 Codex 长任务安心跑完

- AI Quota Bar 会显示当前正在工作的 Codex 任务数量。
- 只在任务运行期间保持显示器、阻止屏保和系统空闲睡眠；任务全部完成后自动恢复正常。
- 多个任务同时运行时会分别计数，不会因为其中一个先结束就提前停止保护。
- 如果偶尔需要合上 MacBook 仍让任务继续，可以单独开启合盖模式。第一次使用需要管理员授权，但不要求 Apple Developer 身份。
- 合盖模式会在任务完成、应用失去联系、电量过低、机器过热、用户关闭或达到 12 小时上限时恢复原来的睡眠设置。

## 更快判断 OpenAI 为什么慢

- 右键面板只展示 `openai.com` 与 `chatgpt.com` 的活跃连接，其他流量不会干扰判断。
- 可以直接看到总下载速度、总上传速度和当前连接数。
- 最近 60 分钟图表让连接高峰、空白时段和持续较久的连接更容易被发现。
- 每个连接对应一个色块：新连接为绿色，持续越久越接近橙色。
- 连接列表会在数据可用时展示域名、应用、线路、持续时间和速度。
- 所有连接监控都是只读的，不会关闭连接或改动 Clash 配置。

## OpenAI 断线时少做几步

- 线路和活跃连接现在直接上下排列，不需要切换标签页。
- 右键面板更窄，但线路与连接列表仍保留足够的浏览空间。
- 最近三次换线记录会简短显示；没有记录时不会浪费高度。
- 继续支持 `🇯🇵`、`日本`、`JP` 等国家筛选，也可以用正则精确匹配线路名。
- 可以手动选择线路，也可以在真正断线时，让应用从筛选结果中选择延迟最低的线路。

自动恢复仍然很克制：打开面板、点击测速或打开开关都不会换线。只有 `openai.com` 与 `chatgpt.com` 连续两轮同时不可达时才会开始恢复；连接成功后立即停止并发送系统通知。

## 日常使用更稳定

- 减少启动时等待系统钥匙串的情况，让菜单更快出现。
- 升级应用时会先停止旧版本，再完整替换应用包并重新启动，降低覆盖运行中应用造成异常的概率。
- 补充了任务检测、睡眠保护、连接历史、线路历史和界面布局等自动化测试。
- README 现已提供完整中英文说明，并清楚解释安装方式、隐私边界和合盖使用注意事项。

## 安装说明

本版本要求 macOS 14 或更高版本，预编译 DMG 面向 Apple Silicon。

公开 DMG 使用 ad-hoc 签名，未经过 Apple 公证。首次打开时如被 Gatekeeper 拦截，请按住 Control 点击应用并选择“打开”，或前往“系统设置 → 隐私与安全性”允许打开。不要全局关闭 Gatekeeper。
