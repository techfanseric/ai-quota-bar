# AI Quota Bar v1.6.0

v1.6.0 把右键菜单升级为面向长时间 AI 编程任务的完整控制中心：它既能保护正在工作的 Codex 任务，也能观察 OpenAI 活跃连接，并在确实发生双域名故障时协助恢复 Clash/Mihomo 线路。

## Codex 任务保护

- 自动检测本机正在执行的 Codex 任务，并展示当前受保护任务数量。
- 只在任务活跃时保持显示器、阻止屏幕保护程序和系统空闲睡眠；任务结束或应用退出后立即释放。
- 增加 Codex 生命周期 Hook 与只读本地状态兜底，降低 Hook 未注册或不可用时漏检活跃任务的概率。
- 增加可选的“合盖继续运行”模式。首次启用时通过管理员授权安装辅助程序，不要求 Apple Developer 身份。
- 合盖租约会在任务结束、应用心跳超时、低电量、严重温度压力、用户关闭或达到 12 小时上限时恢复原有 `pmset` 状态。

## OpenAI 活跃连接

- 固定筛选 `openai.com` 与 `chatgpt.com` 的活跃 Clash/Mihomo 连接。
- 实时展示总下载速度、总上传速度与连接总数。
- 增加最近 60 分钟的堆叠连接图，每分钟采样；一个连接对应一个堆叠单元。
- 连接颜色随持续时间从绿色过渡到橙色，便于区分新连接与长连接。
- 增加紧凑活跃连接列表；在控制器数据可用时展示域名、进程、网络、线路、连接时长和当前速率。
- 所有连接能力均为只读，不会关闭或改写 Clash 连接。

## OpenAI 线路体验

- 线路列表与活跃连接改为上下结构，不再使用 Tab。
- 右键弹出框整体宽度缩小约五分之一，同时为线路和连接列表保留可用的最小高度。
- 最近切换记录最多展示三条，并在无记录时自动收起多余空间。
- 保留普通文本、国家别名与正则筛选，以及按延迟排序和手动切换。
- 自动恢复仍然只由 `openai.com` 与 `chatgpt.com` 连续两轮同时不可达触发；单纯测速、打开面板或打开开关不会换线。

## 稳定性与发布

- Keychain 凭证检查改为非阻塞路径，避免主界面启动时等待系统钥匙串交互。
- 安装流程改为停止旧进程后原子替换应用包并重新启动，避免覆盖运行中签名包导致异常。
- 增加任务检测、睡眠保护、辅助程序、连接历史、线路历史和界面布局测试。
- 正式重写中英文 README，补充安装、公证状态、隐私边界、云同步数据、Clash 配置与源码构建说明。

## 安装说明

本版本要求 macOS 14 或更高版本，预编译 DMG 面向 Apple Silicon。

公开 DMG 使用 ad-hoc 签名，未经过 Apple 公证。首次打开时如被 Gatekeeper 拦截，请按住 Control 点击应用并选择“打开”，或前往“系统设置 → 隐私与安全性”允许打开。不要全局关闭 Gatekeeper。
