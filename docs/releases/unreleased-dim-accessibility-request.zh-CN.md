# 未发布 · Dim「授权」就地弹出系统辅助功能请求（macOS）

右键面板的「暂时离开」一行在「输入即恢复」缺少辅助功能权限时，已经会
显示橙色提示和「授权」按钮。现在「授权」与合盖助手的「安装」按钮一致：
直接在菜单里弹出系统辅助功能请求，然后打开系统设置的辅助功能面板。
macOS 仍要求用户在那个面板里手动完成授权，任何应用都无法自行开启该
权限。指针活动无需此权限即可恢复 Dim；设置 → 通用 → Dim 分区保持不变。

仅限未发布的 macOS 源码。公开 Mac v1.39.6 和 Windows v1.38.6-beta.1
下载保持不变。
