# v1.38.5 — Credential guard and background performance

macOS feature release, build 81.

- Every Codex account seen on this Mac keeps a copy of its credentials outside `~/.codex`:
  `~/Library/Application Support/com.techfanseric.aiquotabar/codex-auth-mirror/<account digest>.json`,
  directory 0700, files 0600, atomic writes. The directory is created on the first write.
- The mirror follows `~/.codex/auth.json` and every backup in the account pool. It only
  follows: switching still happens by atomic rename between auth.json and the pool, and
  mirrored files are never read back, moved, or rewritten.
- The app watches both the `~/.codex` directory and the `auth.json` file itself, and
  syncs on any change; a 10-second background poll backs it up. The moment a gateway
  (magpie and friends) swaps the sign-in, that account's credentials are already safe.
- When an external tool rewrites the sign-in, the accounts section says so and names who
  was switched away and who came in. Switches this app performs itself are not counted
  as external.
- Also fixes a guard that never worked: `URL.resourceValues(forKeys:)` caches resource
  values on the same URL instance — writing one file three times in a row returned the
  same modificationDate every time. The tear-read protection compared that cached value
  with itself, so it always passed and never guarded anything. It now uses a fresh stat.
- Account switching, panel rendering, and cloud sync are unchanged; the watch-account
  and team channels are independent and unaffected.

See [Credential guard mirror](docs/codex-auth-guard.md).

## Lower background work

- Kimi and MiniMax use file events and incremental history checks, with full-scan recovery and periodic reconciliation.
- Codex reuses unchanged, sanitized task metadata. Menu-bar rendering skips unchanged state and closed-menu layout; display discovery follows configuration events.
- Refresh intervals, task detection and animation playback cadence are preserved.
- In a five-minute active-task measurement on one Mac, average CPU fell from 21.76% (60-second baseline) to 12.12%. This is not an idle benchmark or a guarantee: a later active-task window measured 17.65%. Idle below 1% has not been demonstrated; native menu-bar animation redraws remain a hotspot.
- GPU-only animation experiments are not shipped because menu-bar replica playback and appearance equivalence are unverified.

See the [performance audit](docs/performance-audit-2026-10-23.md) for memory measurements, methodology and limitations.
