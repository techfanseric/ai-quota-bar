# AI Quota Bar v1.15.0

本版本新增 GLM Coding Plan 配额监控，并重新整理服务商凭据输入体验。

## GLM Coding Plan

- 在服务商设置中新增 GLM，可与 Codex、Kimi 和 MiniMax 一起刷新和展示。
- 个人套餐可直接填写 Coding Plan API Key；也兼容从用量页面复制的 `quota/limit` cURL 请求。
- 支持新版 5 小时与周积分额度，正确区分周期、剩余积分、套餐等级和重置时间。
- 兼容旧版 Tokens 与 MCP/Search 额度响应；空数据和无效响应不会被误报为连接成功。
- 凭据继续保存在 macOS 钥匙串，历史网页凭据可无损编辑和重新保存。

## 服务商凭据设置

- API Key 输入统一为原生密码框，尺寸、间距和按钮层级更符合 macOS 设置界面。
- 新增显示或隐藏凭据、从剪贴板粘贴和撤销修改操作。
- 仅在内容发生变化时启用保存按钮；保存后自动恢复隐藏状态。
- 测试进度与成功或错误反馈采用稳定的独立布局，不再挤压操作按钮。

## 安装说明

要求 macOS 14 或更高版本，预编译 DMG 面向 Apple Silicon。

公开 DMG 使用 ad-hoc 签名，未经过 Apple 公证。首次打开如被 Gatekeeper 拦截，请按住 Control 点击应用并选择“打开”，或前往“系统设置 → 隐私与安全性”允许打开。不要全局关闭 Gatekeeper。
