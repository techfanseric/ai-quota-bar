# v1.29.0 — 任务结束即时落波，空闲负载大幅降低

macOS build 58。

## GLM/ZCode 任务结束即时识别

- 现场实验证实：ZCode 的 `turn_usage` 账本只在回合到达终态（`completed`/`error`/`cancelled`，含用户取消）时才插入一行，执行期间没有可观察的 running 行。
- 检测改为混合式：开始与进行中仍由 `time_updated` 新鲜度驱动；每次轮询按 rowid 游标消费新落账的终态行，立即把该会话移出活跃集。
- 任务结束/取消的识别延迟从最长约 120 秒缩短到一个轮询周期（2–3 秒），取消语义首次可感知。取消后立即继续的回合受终态时间门控保护，不会被误杀。
- 表结构变化时自动回退为纯新鲜度检测，行为与旧版一致。

## 空闲占用修复（两处单核打满）

- Kimi CLI：wire 转录改为增量解析，从上次消费的换行处续读。此前空闲状态下每轮全量重读数百份历史转录，单核被打满。
- MiniMax：`bg_*` 目录的修改时间随目录列举一次取回，探针文件改用原生 `stat`——此前 `FileManager` 对每个缺失文件抛接一次 ObjC 异常，数千个历史任务目录即可占满一个核。

## 任务波：追逐队列布局（新默认）

- 新增「追逐队列」布局并设为默认：所有任务波在可见弧上首尾相接列队行进，波头恒亮成珠，任意任务数下每道波同时可见、可数。
- 设置中可切回「均匀分布」（原全轨道行为）。
- 环境动画（任务波、离线脉冲）的重绘节奏从 30fps 降至 12fps：每次重绘都是一次完整的 CPU 位图渲染，降帧后空闲渲染负载减半以上，慢速运动在视觉上依然平滑。「减弱动态」时队列以静止姿态停在可见弧上。

## 官网管理台

- `/admin` 新增「打开面板」：平台管理员可免密进入任意团队面板（含早于 `usage_teams` 的仅设备团队），全程不触碰团队密码。
- 仅设备团队轮换邀请码现在明确返回 404，不再静默发出从未持久化的邀请码。

要求 macOS 14+；DMG 面向 Apple Silicon，沿用 ad-hoc 签名，未经过 Apple 公证。
