# v1.30.0 — Codex 账号免登录切换

macOS build 59。

## 切换 Codex 账号不再需要重新登录

- 右键面板新增「Codex 账号」分区：列出当前账号与账号池里的所有备份，点「切换」即对 `~/.codex/auth.json` 与账号池（`~/.codex/accounts/`）做一次原子改名换位——没有登录弹窗，也不用扫码。
- 「登录新账号」会把当前凭据先存入账号池，然后自动打开 ChatGPT 让你登录一次；此后新账号永远只有一键之遥。
- 守卫原则：绝不代替你退出应用。ChatGPT/Codex 桌面版或 `codex` 命令行在运行时，切换请求会挂起并显示横幅（「退出 ChatGPT 后将自动完成切换」），你用正常方式退出后几秒内自动接力完成；文件搬动前的最后一刻还会再查一次运行状态，防止竞态。
- 账号池就地管理：重命名、删除（移入废纸篓）、把以前手动改名的 `auth *.json` 旧备份一键收编。同一账号重新登录会以较新凭据替换旧备份而不是生成重复项；API Key 模式的 auth 文件绝不会被自动处理。
- 每个账号行显示该账号「上次获取到的配额」：5 小时短周期与 Weekly 长周期的剩余百分比及重置时间（悬停查看完整时间戳）。配额快照在每次成功刷新时按账号指纹记录。
- 实现层面：auth 文件解析下沉到本地用量共享内核（与用量账号观测同一套判定）；切换是两次保持 0600 权限的原子改名，全程不读取、不存储任何 token 内容——只用账号指纹和邮箱。

要求 macOS 14+；DMG 面向 Apple Silicon，沿用 ad-hoc 签名，未经过 Apple 公证。
