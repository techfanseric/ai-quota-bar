# v1.27.0 — 左键菜单收起跟随应用，钥匙串一次授权

macOS build 55。

## 左键菜单供应商区可收起

- 「跟随运行中的应用」在左键菜单改为**自动收起/展开**：应用未打开的供应商不再整块移除，而是把该区收起成一行标题，数据仍在原地。
- 标题行可点击手动展开或收起；自动切换与手动操作都记入同一状态，菜单重开、App 重启后保持。
- 菜单栏圆环仍按应用运行状态自动显隐，与 v1.26.0 一致。

## 启动钥匙串授权合并为一次

- 启动时不再分别请求「AI Quota Bar 凭证库」和「kimi-desktop Safe Storage」两个授权：首次交互授权后，Kimi 桌面端密钥缓存进自家凭证库，之后只访问一个条目。
- 后台刷新完全不触碰其他应用的钥匙串条目（macOS 的分区检查在后台也会弹窗）；Kimi 轮换密钥时静默跳过，下次在设置里点「允许读取桌面登录」自动重取。
- 历史遗留条目只在凭证库不存在时才探测，迁移成功后自动删除。

## Kimi 月计划柱图按天切分

- 「Total usage」只有到期日没有开始日，柱图现在按到期日回推一个自然月：每天一条分隔线，悬停显示日期标签（抽稀到最多 6 个）。
- 节奏指针、reserve/deficit 提示和菜单栏圆环的盈余/透支扇形也按该窗口估算。

要求 macOS 14+；DMG 面向 Apple Silicon，沿用 ad-hoc 签名，未经过 Apple 公证。
