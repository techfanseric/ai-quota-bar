# v1.20.0 — 成员用量图表，建团与团队面板一键直达

本次包含 v1.19.0 以来的全部发布改动，macOS 构建号 46。

## 创建、加入和切换

- 「设置 → 用量与团队」默认展示创建团队；已有团队也能直接创建或加入其他团队。
- 切换成功前保留原连接；原团队历史和已归属用量不会转移。创建后加入失败时保留恢复信息，重试不会重复建团。
- 新建团队的管理密码安全保存到 macOS 钥匙串，请另存备份，仅分享邀请码给普通成员。

## 看清每个人用了多少

- App 设置和团队网页新增成员横向对比图，可切换 Tokens、记录数、缓存命中率和估算成本，直接选择成员进入明细。
- 原生设置复用左键菜单的日历与 24 小时绘图组件；网页同样提供 288 格、每格 5 分钟的矩阵。
- 点击日历日期或选择历史日期，查看那一天的五分钟用量；可叠加成员、设备和账号筛选。
- 展示输入、输出、缓存、推理与价格覆盖；未完整定价不会冒充完整成本。团队图表明确使用 UTC，且仅统计已上报数据。
- 服务端按时间桶、价格生效区间和团队聚合，不把原始日志或对话发送到浏览器。

## 成员与管理员的完整入口

- 所有成员点击「查看团队」直接打开只读团队面板，无需手动输入登录信息；可互相查看本团队成员、设备、用量及账号额度记录。
- 「管理团队」使用已保存的管理凭据直达。旧版本没有保存管理密码，已有管理员需要首次补录一次，验证后后续无需重复输入。
- 设置内团队用量默认展开并自动加载，提供 7 / 30 / 90 天范围、刷新、更新时间、加载/错误/空状态，成员行补充记录数、缓存命中率和估算成本。
- 成员只能读取本团队数据；更新邀请码、撤销成员设备和删除额度历史仍仅限管理员。跨团队管理仍在独立认证的 `/admin`。

## 登录和隔离

- App 签发 120 秒有效、只能兑换一次的网页登录票据，服务端仅保存票据哈希。长期设备凭据和管理密码不会放入链接。
- 页面兑换前立即清除地址栏票据；Cookie 使用 Secure、HttpOnly、SameSite=Strict，有效期 8 小时。
- 成员会话持续检查设备授权，设备撤销、退出或 token 轮换即失效；管理票据必须验证同一个团队的管理密码。
- 多标签页登录不同团队时，旧页面操作携带团队校验，避免误操作新登录团队。延迟响应不会覆盖退出或切换后的页面/统计。

## 官网 UI 与发布流程

- 根据真实原生组件重新核对官网：月历、最近 24 小时矩阵、账号切换、未定价状态、统计说明、菜单与配额图、历史周期、设置和移动预览。
- 修复 hero 热力图列宽受小时标签撑开，造成格子交叉的问题；390 / 768 / 1440 宽度验证每张矩阵 288 格，零重叠与越界。
- 官网新增团队网页预览，使用真实成员图表截图；原生团队区域使用真实 SwiftUI 渲染截图，并同步本版中英文 README、入口说明和图片。
- 合并此前未提交的团队／管理页中英文切换、英文反馈页、更新日志中英文排版、站点导航及历史 Release 翻译；修复语言脚本被生产 CSP 拦截的问题。
- 修复更新接口版本字符串规范化依赖遗漏，并验证 GitHub 不可用时的版本回退；同步此前发布记录。

## 验证与部署

- 后端 71 项测试通过。
- Swift 完整回归 386 项，0 失败，5 项环境相关跳过；另有 2 项真实 HTTP 联调通过，覆盖创建、加入、成员/管理直达、票据重放和退出撤销。
- 浏览器验证成员只读视图、管理员视图和无效票据提示；原生中英文创建及已连接状态渲染通过。
- 自部署先执行 `cloudflare/migrations/0008_team_handoff.sql`，再部署 Pages；仅新增短时票据表和索引，不修改用量历史。

macOS 14+，Apple Silicon。公开应用为 ad-hoc 签名，未进行 Apple 公证。

## English

Create or join teams directly in Settings, including an explicit switch flow for connected Macs. Members open their read-only team dashboard in one click and can see fellow members’ usage, devices and quota accounts. Managers open management using credentials saved in macOS Keychain; existing managers enter their password once. Team summaries load automatically. Browser links use short-lived, single-use tickets, and member sessions are revoked with device access. All mutations remain manager-only, and cross-team administration stays in `/admin`.

Member comparison bars and drill-down calendars now show each person’s daily and 5-minute usage, with device/account filters and token, record, cache and cost metrics in both the app and browser. Team charts use UTC and show only reported data.

This release also corrects website previews against the native app, fixes overlapping hero heatmap cells, and fixes update-manifest version normalization. It includes pending bilingual team/admin interfaces, the English feedback page, changelog localization and navigation improvements. Self-hosted deployments must apply migration 0008 before deploying.
