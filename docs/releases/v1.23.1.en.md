# v1.23.1 — Calmer menu expiry text, website team preview aligned

macOS build 50.

## Left-click menu

- The MiniMax subscription line drops the repeated "expires" wording and shows just the date.
- When the provider-header subscription subtitle runs long, it now shrinks by at most 10% instead of being truncated.

## Website

- The homepage "who used how much" preview card reproduces the released /team dashboard: the same page heading with range tools, unified 32 px controls with 6 px corners, and the released member-bar and hour-chart layout.
- Removed legacy `.activity-*` rules from the retired hero demo: their class names collide with the real /team frontend and squashed the embedded hour chart to about 20 px tall.
- The preview card lives in a column whose width varies continuously with the viewport, so its narrow layout now keys off the card's own width via container queries, with viewport media queries as a fallback for engines without support.

## Scope

This release does not change monitoring, upload, retention or signing behavior; the performance and upload fixes from v1.23.0 are unaffected. The on-device performance audit is recorded in `docs/performance-audit-2026-09-20.md`.
