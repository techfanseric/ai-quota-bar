# v1.24.0 — Automatically detect Kimi desktop and web sessions

macOS build 52.

## Kimi quota sources

- Automatic mode discovers valid desktop sessions, saved web sessions, CLI credentials and readable browser sessions without manual source selection. A saved API key retains top priority.
- Supports the newer desktop client's encrypted session store through read-only access; does not change client files or take over refresh-token rotation.
- Settings show the most recently successful source. Manual selection, browser import and authorization controls are grouped under advanced options.
- Displays Code short-window and seven-day quotas, plus membership totals when available, preserving separate reset times and account attribution.
- Background browser discovery avoids Keychain prompts and caches results. Multiple different accounts require selection; network errors after selecting a valid desktop or web session do not switch accounts.

## Availability and validation

Automatic desktop access was verified on a real device. Browser import and overseas accounts have not been verified on-device. Availability depends on session validity and local access permissions. If a desktop session expires, restore a valid login in the official client; this app does not refresh its credentials.

Requires macOS 14+. The Apple Silicon DMG retains ad-hoc signing and is not Apple-notarized. MiniMax continues to use its API key directly and does not depend on its desktop client.
