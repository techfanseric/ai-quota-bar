# v1.26.0 — 菜单跟随运行中的应用

macOS build 54。

## 跟随运行中的应用

- 设置 → 显示新增「跟随运行中的应用」开关（默认关闭）。开启后，菜单栏与左键菜单只显示对应桌面应用已打开的供应商：ChatGPT（Codex）、ZCode（GLM）、Kimi、MiniMax Code。
- 应用启动或退出时自动出现或隐藏，无需手动调整；应用都未打开时菜单栏保留占位显示，确保状态栏入口始终可点。
- 左键菜单被全部隐藏时会给出提示卡片，可一键改回「显示全部供应商」。

## 范围

本次仅为显示层功能：配额后台刷新、数据来源、账号处理与手机看板均不受影响；供应商的暂停、排序与单项隐藏设置照常生效。

要求 macOS 14+；DMG 面向 Apple Silicon，沿用 ad-hoc 签名，未经过 Apple 公证。
