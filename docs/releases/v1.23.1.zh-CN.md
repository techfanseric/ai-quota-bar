# v1.23.1 — 菜单到期行更简洁，官网团队预览对齐

macOS build 50。

## 左键菜单

- MiniMax 套餐到期行去掉「到期 / expires」字样，只保留日期，减少重复文案。
- 供应商表头右侧的套餐副标题过长时按最多 10% 轻微缩小，不再直接截断。

## 官网

- 首页「谁用了多少」面板预览卡复现真实 /team 页面：页头标题与范围工具行同款，控件统一 32px 高、6px 圆角，成员条形图与小时图分列样式一致。
- 移除旧版 hero 演示遗留的 `.activity-*` 规则：这些类名与 /team 真实前端同名，残留样式会把首页嵌入的小时图压成约 20px 高。
- 预览卡位于宽度随视口连续变化的栏目内，窄版布局改用容器查询按卡片自身宽度触发，并为不支持的引擎保留视口媒体查询兜底。

## 范围

本版本不改变监测、上报、数据保留或签名方式；v1.23.0 的性能与上传修复不受影响。性能审查记录见 `docs/performance-audit-2026-09-20.md`。
