# 已纳入 v1.39.4 · 一分钟轻量模式（macOS）

默认开启「设置 → 通用 → 系统 → 轻量模式」。左右键面板、设置和警告窗口关闭满一分钟后，释放可重新创建的界面资源；一分钟内重新打开则取消回收。首次使用前也不提前加载隐藏面板。

菜单栏 ring 的额度、趋势、模型流光、悬停明细与提醒继续运行，后台额度刷新、任务保护、Dim、同步、上报和 LAN 看板不暂停。可见、最小化或带有 sheet 的窗口不会被释放。

已保存设置、账号及历史保留；设置页签与窗口位置在重建时恢复（受显示器布局约束）。未保存的临时输入可能清空。重新打开界面需要少量重建时间；频繁开关界面时可关闭轻量模式。实际内存收益取决于已打开页面和系统缓存，不承诺固定 MB。

已纳入 [v1.39.4](v1.39.4.zh-CN.md) 发布。Windows 未移植此功能。
