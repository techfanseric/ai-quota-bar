# Windows DPI / Watch 修复记录（未发布）

日期：2026-11-01。Mac 稳定版维持 v1.39.1，Windows 已发布 ZIP 维持 v1.38.6-beta.1；本次提交不创建 Release、不替换下载包。

## 修复

- 托盘控制中心使用点击所在显示器的工作区，窗口创建和 DPI 切换结束后重建字体与布局，避免旧坐标和新字体混用。
- 标题与账号按实际文字高度排列；长账号、套餐省略；额度元数据改为自动换行，避免把测得的像素宽度再次按 DIP 缩放。
- 重建时释放旧卡片，关闭时释放刷新计时器。
- Codex 额度刷新后请求 Watch 报送，不再只等独立的十分钟计时器；保留定时刷新。
- Providers 显示等待、成功时间/账号数量、失败或撤销状态；发布失败日志包含 HTTP/网络错误类型。
- 周期长度未知或起点无效时发布 `startsAt: null`，不再发送起点等于重置时间的非法窗口；采样时间缺失时使用本次本机快照时间，不用未来的重置时间冒充采样时间。
- Mac/Windows 发布字段均为 publisher、account、plan 和 windows（name、remainingPercent、resetsAt、sampledAt、startsAt）。没有 eye 字段；Mac 读取成功后生成 Watch 来源图标。不能把“无眼睛”等同于“发布失败”。
