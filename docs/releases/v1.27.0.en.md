# v1.27.0 — Collapsible menu sections, one Keychain prompt

macOS build 55.

## Collapsible provider sections in the left-click menu

- "Follow running apps" now **collapses** a provider's section in the left-click menu when its desktop app isn't open, instead of removing it — the header row stays, the data stays in place.
- Click the header to expand or collapse manually. Automatic switching and manual toggles share one remembered state across menu reopens and app restarts.
- The menu bar ring still appears and disappears with app presence, as in v1.26.0.

## One Keychain authorization at launch

- Launch no longer asks separately for the "AI Quota Bar" vault and the "kimi-desktop Safe Storage" item: after one interactive authorization, the Kimi desktop key is cached in our own vault, so only one item is ever accessed.
- Background refreshes never touch another app's Keychain item (macOS partition checks prompt even in non-interactive mode). If Kimi rotates the key, refresh skips silently and the next "Allow Desktop Access" click in Settings re-authorizes.
- Legacy Keychain items are only probed while no vault exists, and are deleted after a successful migration.

## Kimi monthly bar is segmented by day

- "Total usage" only carries an expiry date; the bar now derives a one-calendar-month display window from it — one divider per day, date labels on hover (thinned to six at most).
- The pace tip, reserve/deficit hint, and the menu bar ring's surplus/deficit sectors are estimated from the same window.

Requires macOS 14+; the DMG targets Apple Silicon and keeps the ad-hoc signature without Apple notarization.
