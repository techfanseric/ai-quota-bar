# AI Quota Bar v1.14.0

本版本新增服务商暂停能力，并统一手机仪表盘的状态信息展示。暂停服务商不会删除凭据，可随时恢复使用。

## 暂停单个服务商

- 在服务商设置中可关闭「使用此服务商」，暂停该服务商的配额刷新、菜单显示、阈值提醒和任务合盖保护，同时保留已有凭据。
- 菜单中的服务商标题旁新增快捷暂停按钮；设置列表会用暂停图标标记已停用项。
- 暂停状态会持久保存；重新启用后立即刷新数据。
- 固定菜单栏服务商被暂停时自动回退到其他启用中的服务商；所有已配置服务商均暂停时显示明确的恢复指引。
- 正在刷新时发生的重复刷新请求会在当前请求完成后补跑一次；请求途中被暂停的服务商结果不会重新写回界面。

## 手机仪表盘状态整合

- 「Protection / 保护」区块更名为「Status / 状态」，更准确地覆盖任务保护和配额状态。
- 配额错误改为红色状态项并入滚动状态栏，不再占用配额卡片上方的独立空间。
- 无标签的状态项自动隐藏空标签，保持紧凑排版。

## 安装说明

要求 macOS 14 或更高版本，预编译 DMG 面向 Apple Silicon。

公开 DMG 使用 ad-hoc 签名，未经过 Apple 公证。首次打开如被 Gatekeeper 拦截，请按住 Control 点击应用并选择“打开”，或前往“系统设置 → 隐私与安全性”允许打开。不要全局关闭 Gatekeeper。
