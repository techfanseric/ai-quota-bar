# v1.35.0 — 占位图标三选一、周趋势曲线、诚实的更新时间

macOS build 68。这一版同时把安装方式换成了安装包。

## 更新装方式：双击就好，不用挂载不用拖

之前是 DMG，下载 → 挂载 → 拖进「应用程序」。现在是安装包，**双击一步到位**，而且多干了两件拖拽做不到的事：

- **替换之前会先退掉正在运行的旧版**，装完再拉起来。一个菜单栏 app 更新完悄悄从菜单栏消失、要等你注意到才回来，比"多点一次"糟糕得多
- 装完自动把安装包本身删掉，不留在下载文件夹里

两个脚本（`preinstall` / `postinstall`）都以 root 运行，都已经在真机上跑通两遍验证过。

**需要知道的一件事**：安装包**没有开发者签名、也没有经过 Apple 公证**（里面的 app 是 ad-hoc runtime 签名）。从浏览器下载后双击，macOS 会比装 DMG 时提示得更重一些。如果提示"无法验证开发者"，按 Control 点击安装包选"打开"，或者到「系统设置 → 隐私与安全性」里点"仍要打开"，之后就正常了。

不想装安装包的话，release 里仍然附带 DMG，两者功能完全一样。

## 菜单栏占位图标：从开关变成三选一

原来只有一个"占位时是否显示供应商数量"的开关——那是两种形态的布尔表达，塞不进第三种。现在改成三选一：

| 选项 | 菜单栏显示 |
|---|---|
| **OpenAI 连通性**（默认） | 哑色开环 + 中心一枚连通性记号（对勾 / 叉 / 探测中） |
| 供应商数量 | 哑色环 + 已启用的供应商数量 |
| 品牌字母标 | 复刻 App 图标构图的字母标 |

默认换成连通性，是因为占位的时候本来就没有额度可显示，而"现在能不能顺利拉起 ChatGPT"是那一刻唯一还成立、又真的在意的信息。没有它，占位期间菜单栏就是一个纯装饰的死环。

这个记号**刻意做得不像「Codex 掉线」**：掉线是整环变红 + 中心红药丸 + 呼吸脉冲三件事叠加，这里环**始终**保持哑色中性、完全静态，只有中心记号承载状态。缩到二十几像素也不会误读。可达状态用的是中性色而不是绿色——这个 app 的语义色只有警示琥珀和危险红，绿色会变成第三种要记住的约定。

tooltip 会追加一行说明（可达 / 不可达 / 正在探测），否则菜单栏那二十几像素里的记号没人解释。

## 只有周窗口的账号，环内终于有形状了

一个只有 Weekly、没有 5h 的账号，环内原本只有一个"快慢"单值——而这个值横跨好几天，说不出任何形状。现在：

- 这种账号的**外环和内圈都按 Weekly 计算**。你设的是"环显示 5h"，但根本没有 5h 可显示，退回 Weekly 才是你真正想问的那个额度
- **内圈画趋势曲线**，而不是原来的双向节奏扇形——周窗口跨好几天，单值没有信息量，形状才有
- 曲线需要**至少两个采样点**才存在（一个点画不出线，只会在扇形位置留一个孤零零的圆点，看着像渲染坏了），最多 24 个点（菜单栏只有二十几像素宽，再多只是锯齿）
- 横轴是采样在**本窗口时间轴上的位置**，不是它在数组里的序号。按序号排会让两个点横跨整个环，看上去像一周走了个来回，那是假的

内圈是独立设置项。如果你把内环指向了别的窗口，扇形就保住那块地盘——**周窗口超额 10% 恰恰是最该被看见的信号，不该被趋势曲线挤掉**。

## 关注账号显示的时间，以前是错的

账号行右边那个时间读的是最后一次采样的时刻。它显示成 `Watch · 10/11 23:59`，而数据其实是五分钟前抓的。

原因是两跳接力：`CodexUsageDataMapper` 把真实抓取时刻丢掉了（`sampledAt: nil`），发布投影于是拿 `endTime` 兜底——而 Codex 的 `endTime` 就是 `resetsAt`，是窗口的结束时刻，可能在好几天之后。**数据是新的，时间是错的，这比没有时间更糟**：你会以为是坏了或者没同步。

修了四层：

- **源头** —— 每行 Codex 额度带上真实的抓取时刻
- **发布** —— 不再拿窗口边界兜底
- **读侧** —— 采样时刻晚于"现在"就不是时间，是故障报告，退回发布时刻
- **服务端** —— publish 时把落在未来的采样时刻收敛到发布时刻

后两层是为了**对方不升级 app 也能正确显示**。已经在服务器上验证过：对方那台还是老版本、照旧发来未来的时间，服务端当场改写，所有读侧拿到的都是对的时间。`resetsAt` 是独立字段，不受影响——"超额 35% · 10/11 23:59"那行重置时间照常显示。

## 顺带修正

- 账号名放不下时**截断而不是缩字号**。缩了会让同一区块里各行字号不一致，远看像某个账号"特殊"
- 宽度不够时**先让套餐名让位**——套餐名是装饰，账号名才是身份
- 时间戳是原子的，不会被截成半个 `10/5 11:1`
- 跨天的时间戳补上日期（`9/28 11:50`），管理后台也一样。只有 `11:50` 读不出是哪天的快照
