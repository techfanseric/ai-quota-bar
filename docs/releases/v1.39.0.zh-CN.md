# v1.39.0 — Codex 重置收件箱与清晰的 Dim 状态

适用于 macOS 14+、Apple Silicon。Windows 维持独立预发布 v1.38.6-beta.1，本次 Mac 功能不会自动进入 Windows ZIP。

## 公开重置消息持续提醒

- 左键菜单接入 codex-reset.com 和 codex-resets.com 的公开消息，区分线索、预告、已报告重置及 Banked 信息，保留来源和原文链接。第三方公告不能证明你的账号已经重置。
- 未读时菜单栏显示橙色铃铛，每 0.75 秒切换明暗；系统开启「减少动态效果」时常亮。新消息尝试系统通知，仍未读时每五分钟再次提醒，直到明确确认。
- 打开原文、关闭通知不会自动已读。菜单内逐条或全部确认后保持面板打开；原文按钮先关闭面板再打开浏览器。旧通知的确认只作用于它携带的消息版本，不会清除新消息。
- 历史按钮始终可用，展示最近 30 天记录；更旧的未读继续保留。最新一条明确预告、已报告重置或 Banked 消息在已读后仍常驻，不重新提醒。重启保留已读和未读状态。
- 独立轮询三个 feed，单站失败不清空未读；状态/内容升级会重新提醒。系统通知受权限和专注模式影响，菜单栏提示不依赖通知权限。正式版本不包含测试提醒入口。

## 远程连入也能看见 Dim 开着

「暂时离开」调暗开启时，菜单栏追加常亮的屏幕＋月亮标记。额度图标、任务动画和重置铃铛显示期间都保留 Dim 状态；恢复屏幕后标记消失。标记不使用额度进度环，避免将开关状态误读为百分比。

## 菜单和官网同步

菜单材质圆角、尺寸变化与阴影保持一致，内容更新复用同一面板。官网和双语文档补齐近期亮度、账号来源、凭据镜像与 Windows 能力差异；Windows 介绍新增安装/更新、Codex CLI 回退、Watch、任务保护、手机看板和明确限制。官网更新日志标记独立 Windows 公测版，Mac 稳定版与 Windows 版本分别维护。

仓库发布规则新增推送前官网影响评估、双语内容与版本门禁，以及部署后的生产核验。测试、打包、校验和及实际发布结果见本版本发布清单。

安装包沿用现有 ad-hoc 应用签名；未使用 Developer ID 安装包签名或 Apple 公证。
