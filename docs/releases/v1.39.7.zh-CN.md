# v1.39.7 · Magic Keyboard 重连后继续调节外接屏亮度

macOS 1.39.7 (90) · Windows v1.38.6-beta.1

开启跟随指针的亮度键并授予辅助功能权限后，把指针移到支持的外接屏上，按 F1 或 F2 调节亮度。两款已验证的蓝牙 Magic Keyboard（产品 ID 0x029A 和 0x0267）重连后会自动恢复亮度键映射。开启「登录时启动」即可在 Mac 重启登录后继续使用。已有的自定义键位优先。

Magpie 是可选组件。未安装时，Codex 沿用现有数据源读取当前已登录账号。使用 Magpie 的可见额度环每五秒读取本机缓存，网关异常时常规刷新回退到当前账号。仅当本机服务商 ID 或显示名为 Magpie 时才识别该网关，指向同一地址的别名也受支持。

右键面板「暂时离开 → 授权」会先请求辅助功能权限，再打开系统设置。完成授权后，可用键盘活动恢复亮度。
