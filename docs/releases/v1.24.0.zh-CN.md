# v1.24.0 — 自动识别 Kimi 桌面与网页登录

macOS build 52。

## Kimi 额度来源

- 默认自动检测有效的 Kimi 桌面登录、已保存网页登录、CLI 和可读取的浏览器登录，无需手动选择来源；已保存的 API Key 保持最高优先级。
- 支持新版桌面客户端的加密登录存储，只读凭证，不修改客户端文件或接管 refresh token。
- 设置页显示最近成功的数据来源；手动来源选择、浏览器导入和授权入口收进高级选项。
- 分别展示 Code 短窗口、7 天额度及可获得的会员总额度，保留各自重置时间和账号归属。
- 后台浏览器检测不弹出钥匙串授权，缓存检测结果；多个不同账号不会自动任选一个。选定有效桌面或网页登录后的网络错误不会切换账号。

## 使用与验证范围

桌面自动读取已在本机实测。浏览器导入和海外账号尚未完成实机验证；来源是否可用取决于登录有效期和本机读取权限。桌面登录过期时，请在官方客户端恢复有效登录，App 不自行刷新官方凭证。

要求 macOS 14+；DMG 面向 Apple Silicon，沿用 ad-hoc 签名，未经过 Apple 公证。MiniMax 继续直接使用 API Key，不依赖桌面客户端。
