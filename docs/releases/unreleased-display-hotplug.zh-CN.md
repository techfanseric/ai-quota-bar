# 未发布 · 显示器热插拔刷新与退出保护（macOS）

**设置 → 通用 → Dim** 现在会感知显示器的接入与拔离，并自动重建屏幕
列表，新接入的显示器不再需要手动点「刷新读数」。EDID 里没有产品名的
显示器仍显示为通用的「Display N」——这个名称来自显示器固件，本地无法
凭空生成。

结束或启动 ChatGPT／Codex 现在改为必须显式注入的能力。只有生产环境的
应用实例被允许退出、重启桌面版客户端；测试、预览和渲染夹具一律拿到惰性
默认值，因此跑测试不会再关掉你正在使用的 ChatGPT 窗口。账号切换的
「自动」模式行为不变：当你主动请求切换账号时，应用仍会按设计退出并
重启桌面版客户端。

仅限未发布的 macOS 源码。公开 Mac v1.39.3 和 Windows v1.38.6-beta.1
下载保持不变。
