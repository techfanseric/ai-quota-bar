# v1.19.0 — 用量与团队，多团队隔离

本次覆盖 v1.18.0 之后的全部发布改动。

## App：一个入口管理一个团队

- 合并 Usage 和 Sync 为「用量与团队」，在设置内直接创建或加入团队，保存一次性邀请与管理凭据。
- 集中查看团队成员、设备、账号与 7 / 30 / 90 天汇总；本机统计继续独立可用。
- 本机用量上报与账号配额共享分别开关，集中展示同步状态和日志。
- 成员通过口令在另一台 Mac 加入；退出时撤销当前设备凭证并暂停共享。

## 多团队的数据与权限边界

- 配额与用量统一使用团队设备凭证；服务端强制团队作用域，其他团队不能读取或删除数据。
- 团队隔离覆盖数据库主键、设备身份、缓存、上传队列和异步响应；切换团队时丢弃旧请求结果，旧的无归属队列不会上传。
- 防止仅凭设备 ID 接管已有成员身份；阻止带凭证请求自动跟随重定向。
- 团队管理员在 `/team` 清理本团队账号、撤销成员设备；删除记录进入审计。普通设备凭证不能删除云端账号数据。
- 跨团队数据、D1、旧版历史记录与删除审计集中到独立认证的 `/admin`，从普通设置移除。
- 新增团队配额表与审计表；旧表保留只读，不根据邮箱或账号名称猜测数据归属。团队配额历史按服务端时间保留 90 天。

## 升级须知

旧版共享同步凭证不再接受。升级后在「设置 → 用量与团队」创建或加入团队继续共享；已有团队设备凭证可继续使用。本机统计不受影响，旧云端数据保留在管理员后台只读，不能自动归入新团队。创建或加入会启用两类共享，之后可以分别暂停。上报包含账号标签（可能含邮箱）和统计元数据，不包含供应商凭证或对话内容。

macOS 14+，Apple Silicon。应用使用 ad-hoc 签名，未进行 Apple 公证，首次打开可能需要按 README 的系统设置说明允许打开。

## English

Usage and Sync are now **Usage & Team**, with native team creation/joining, independent usage/quota sharing controls, team summaries and sync diagnostics. Server authorization, data keys, caches, queues and in-flight responses are scoped to the team. Owners manage only their team at `/team`; platform-wide data, legacy history, D1 and deletion audit live behind independent `/admin` authentication. Legacy shared-token sync stops working: upgrade and create or join a team. Local statistics remain available, old cloud records stay read-only, and team quota history is retained for 90 days.
