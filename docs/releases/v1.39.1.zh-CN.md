# v1.39.1 · 提醒保留额度圆环与菜单账号脱敏

macOS 1.39.1（构建 84）。Windows 保持独立预发布 v1.38.6-beta.1。

- Codex 重置消息未读时保留全部额度圆环，C 改为常亮黄点，仅 Codex 单元每 0.75 秒在黄色与正常配色间交替，额度数据继续更新。开启「减少动态效果」时黄色常亮，Dim 标记仍可见。任务波纹暂停，全部已读后恢复；显示选择未包含 Codex 时临时追加其单元。
- 「设置 → 通用 → 账号显示」新增「菜单账号脱敏」，默认关闭。左右键菜单的账号名和邮箱显示如 a****g@example.com，覆盖悬停、删除确认、外部切换详情；开启时暂停菜单重命名，操作状态使用通用文字。设置页面不在覆盖范围，邮箱域名和部分名称字符仍可见。
- 脱敏只改变菜单显示，账号身份、切换、采集与同步保留原始数据，手机看板使用独立开关。这两项功能仅适用于 macOS。
- 显式启动参数 --test-reset-alert 可生成标注「本机测试」的内存提醒，走真实提醒路径，确认或重启后移除，不改写真实公告。
- 中英文官网演示同步黄点圆环提醒，并更新脱敏说明、平台能力及下载版本。

双击 PKG 覆盖安装到 Applications。需要 Apple Silicon、macOS 14+。应用使用 ad-hoc 签名，安装包未签名，未经 Apple 公证。第三方重置公告不代表个人账号额度已重置；系统通知展示受 macOS 设置影响。
