# v1.38.0 — 亮度键跟随指针，Dim 支持分屏设置

macOS 稳定版，build 75。本次发布包含 2026-10-19 的屏幕亮度相关更新。Windows 仍使用独立的 v1.38.0-beta.1 测试版。

## 亮度键控制指针所在屏幕

- 键盘的屏幕亮度键只调节鼠标指针所在的显示器，支持长按连续调节。
- 内置屏使用系统亮度；支持 DDC/CI 的外接屏优先调节硬件亮度，降到硬件最低后用 Gamma 继续压暗。组合范围与 MonitorControl 默认方式一致，最低保留 15% 色表输出。
- Option + Shift + 亮度键可精细调节。普通亮度键不会改写保存的 Dim 目标。
- 在 Dim 或设置预览期间按亮度键，先恢复原亮度，再调节所选屏幕，避免两种控制相互覆盖。
- 「设置 → 通用」新增亮度键开关与辅助功能授权入口。使用此功能时请退出 MonitorControl，避免两个应用同时处理亮度键和 Gamma。

## Dim 按屏幕设置与即时预览

- 每块屏幕可独立保存目标亮度，并显示当前硬件亮度读数。
- 拖动滑块即时预览所选屏幕；松开后移动鼠标或按任意键恢复，离开设置页也会恢复。不再等待固定的预览倒计时。
- Dim 按钮旁的「智能还原」默认关闭：未勾选时，再次点击按钮或长按菜单栏图标右键才恢复；勾选后支持输入活动自动恢复。
- 不创建软件遮罩，不修改显示器的对比度或 RGB 增益。恢复时使用调暗前保存的硬件亮度与原色表，并支持异常退出后的恢复。

## UU 远程连接时保持本地亮度

- 修复 UU 连入或退出时 Gamma 被重置、按钮仍显示“恢复”但本地屏幕变亮的问题。Dim 期间会检查并补回被重置的 Gamma，显示器重新连接后按稳定标识重新匹配。
- 普通亮度键使用的 Gamma 调暗同样支持重置后的保持；从这种亮度进入 Dim 时按原始色表计算，避免重复压暗。
- 本机短测确认：补回本地 Gamma 时，UU 远程画面保持正常。未修改 UU 配置。

## 验证

68 项相关 Debug 测试通过；内置屏及两块外接屏分别做过小幅调节与恢复验证。发布配置的测试编译受已有菜单栏测试调用 Debug 专用方法的问题影响；发布版应用构建正常。
