# v1.39.6 — Pace in collapsed Codex account rows

macOS 1.39.6 (build 89). Windows remains its separate v1.38.6-beta.1
prerelease and does not include this change.

## Pace in collapsed rows

When a Codex account is collapsed in the left-click menu, AI Quota Bar shows
pace (reserve or deficit) between the account name and its remaining quota, so
you can tell whether the current pace lasts until reset without expanding the
account.

Pace and remaining quota use the same window: whichever window the percentage
on the right describes is the window the pace describes. When several windows
exist, expand the account to switch between them.

Pace appears only when the selected window is current and has enough data. An
expired window, a cloud sample past its freshness limit or insufficient data
shows no pace rather than borrowing another window's value. A deficit turns the
label red; other results use the secondary color.

When space runs out, the plan name is dropped first and the account name
truncates; the remaining quota and pace stay intact.

## Scope

This release changes only the collapsed Codex account row in the macOS
left-click menu. Quota reads, sync, alerts and task protection are unchanged
for Codex, Kimi, GLM and MiniMax, and no credential access, network request or
upload is added. Requires macOS 14+ on Apple Silicon. The app is ad-hoc
signed; the installer is unsigned and not Apple-notarized.
