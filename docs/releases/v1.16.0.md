# AI Quota Bar v1.16.0

本版本支持自由组合菜单栏 Ring 服务商，并补齐 MiniMax 与 GLM 的额度环显示。

## Ring 自由组合

- 将显示方式与服务商选择分开：常驻显示或工作感知，搭配 Codex、Kimi、MiniMax、GLM 多选。
- 支持仅显示 MiniMax + GLM、单独 GLM 等组合，并提供全选操作。
- 原“全部”和“工作感知”迁移为全部服务商；原单家选择保留为对应组合。
- 关闭的供应商从 Ring 选项及全选中排除，重新启用后恢复为可选项。
- 至少保留一家已启用的选择，关闭的供应商不再错误计入这一检查。

## 额度与活动显示

- MiniMax 和 GLM 无需任务检测即可显示最新剩余额度，随现有额度刷新机制更新。
- GLM 优先显示 5 小时额度，避免误取周窗口；耗尽至 0% 时仍保留空环。
- 工作感知下，选中的 MiniMax、GLM 常驻；Codex/Kimi 显示活跃服务商，空闲时保留选中范围内剩余额度最少的一家。
- 没有可展示额度时保留状态入口，不将缺失数据误报为正常额度。
- 中英文设置文案与项目说明同步更新，并补充 GLM Ring 能力调研记录。

## 安装说明

要求 macOS 14 或更高版本，预编译 DMG 面向 Apple Silicon。

公开 DMG 使用 ad-hoc 签名，未经过 Apple 公证。首次打开如被 Gatekeeper 拦截，请按住 Control 点击应用并选择“打开”，或前往“系统设置 → 隐私与安全性”允许打开。不要全局关闭 Gatekeeper。
