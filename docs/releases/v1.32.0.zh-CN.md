# v1.32.0 — 暂时离开一键调暗、合盖调暗与 Clash 面板自适应

macOS build 61。

## 暂时离开：一键调暗所有屏幕

- 右键保护面板新增「暂时离开 · 调暗所有屏幕」：点击后所有屏幕瞬间盖上一层黑色遮罩（屏幕保护级别窗口），同时内置屏背光归零、外接显示器通过 DDC/CI 压暗；移动鼠标或按任意键立即恢复。
- 长按右键状态栏图标 0.6 秒可直接触发调暗，快速右键仍打开面板。
- 遮罩黑度可在设置窗口 General 页调节（60–100%，默认 90% 半透明）：低于 100% 为纯遮罩模式、不动背光，100% 全黑才做真实调暗。
- 键盘恢复依赖辅助功能权限的 listen-only 事件监听，未授权时静默降级为仅鼠标恢复。
- App 启动时会恢复上次崩溃/强退遗留的调暗状态，不会让屏幕一直黑着。

## 合盖工作期间自动调暗内置屏幕

- 合盖保护运行期间（有任务保持唤醒时）自动把内置屏幕压到最低亮度，外接显示器不受影响；系统自动亮度回升会被持续对抗。
- 内置屏亮度值会持久化，异常退出后下次启动可恢复原亮度。

## Clash 面板高度自适应屏幕

- 右键 Clash 面板从固定基准高度改为按所在屏幕的可用高度自适应：小屏上先压缩账号区（内部滚动），再让连接列表让位，最后账号区收起为标题行，不再出现连接列表被挤死或尾部被裁的问题。
- 显示器插拔、重排时自动按新屏幕重新计算。

## 检测准确性

- Kimi 桌面 agent 改用会话状态账本作为权威生命周期来源：任务结束立即判不活跃（不再滞留最长 120 秒），开始立即亮起；心跳仅作为崩溃兜底。CLI 的静默窗放宽到 10 分钟，长工具调用不再闪烁掉出活跃集。
- 新增 Kimi Work（daimon）桌面运行时检测，以「Kimi Work」标签出现在任务列表中。
- Codex hook 任务新增 10 分钟 TTL 回收：进程被 kill -9 或 Stop hook 丢失时不再留下把保护环永久钉在工作态的「幽灵任务」。
- Claude Code 的模型归因改为跟随转录中最新一条 assistant 消息：会话切回官方模型后立即不再计入 GLM/MiniMax。
- 切换或重新登录 Codex 账号后，左键菜单的当前账号立即刷新，不再等最长 60 秒。

## 管理控制台

- 账号额度详情重构为与 App 左键菜单同款的「供应商 → 账号 → 模型列」层级，同一账号每个模型并排一列；新增搜索、全部展开/收起、重置视图。
- 展开账号时按需懒加载最长 168 小时的额度历史；时间显示在中文界面使用 UTC+8（英文保持 UTC）。
- 图表按容器实际宽度绘制，窄列自动做减法；新增 MiniMax、智谱 provider 图标。

## 本地数据

- 本机用量数据库自动瘦身：已确认上云的事件在本地保留 40 天（覆盖图表读取的 35 天窗口）后自动清除，空闲页超过 64 MB 时压缩回收；待上传、被拒和纯本地记录永不自动删除。
- 任务检测轮询的日志只在活跃任务数变化时记录，MiniMax 检测器跳过过期后台目录，显著降低每日日志与磁盘扫描开销。

要求 macOS 14+；DMG 面向 Apple Silicon，沿用 ad-hoc 签名，未经过 Apple 公证。
