# v1.38.0-beta.1 — Windows public beta, and the Codex fetch chain fixed

Windows build 74, a public beta (prerelease). Two things in one release: **the Windows edition is downloadable for the first time** — the macOS menu bar app rewritten module by module in C# / .NET 8 as a native tray app — and the Codex fetch chain on Windows is brought up to macOS behavior: the system proxy is honored, `chatgpt_base_url` in `~/.codex/config.toml` overrides the base URL, and tokens refresh proactively before expiry. The Mac stable release remains v1.37.0 and is untouched by this one.

## The Windows edition, in public beta

Left-click the tray icon for the quota panel (ring gauges, model rows and usage bars follow the Mac design language); right-click for the native command menu. Features were migrated item by item against the specs in `docs/win-migration/analysis/`:

- **Codex**: reads the OAuth / PAT sign-in and the multi-account pool from `~/.codex`, with 5h / Weekly dual-window quotas; hides itself when not signed in
- **GLM**: the API key is the only required field, with cURL import as an optional advanced path; **MiniMax**: paste a token in settings and it is on
- **Kimi**: desktop / web sessions and CLI `/status` parsing
- **Clash / Mihomo**: local controller auto-discovery, group switching, latency tests, a connection overview and auto-recovery
- **Task protection**: `PowerCreateRequest` keeps the machine awake while a task runs, with a battery safety net
- **Mobile dashboard**: read-only HTTP + SSE on port 18765, reusing the original PWA assets
- **Teams**: Cloudflare Worker client for create / join / usage reporting / quota upload

Credentials are encrypted with DPAPI (CurrentUser) into `vault.bin`; silent launch at login, a single-instance guard, light / dark / follow-system themes, bilingual text and file logging are all in. Local verification (Windows 10 19045): all 529 unit / integration tests pass, the Clash integration tests execute against a real controller, and the dashboard and task→keep-awake chains were exercised on the machine.

## The Codex fetch chain, aligned with macOS

Three fixes, all of the shape "the Windows port copied the letter of the implementation and dropped the behavior macOS had been leaning on":

- **The system proxy is honored.** Codex quota requests and Clash probes now go through the system proxy — networks that only egress via a proxy are no longer bypassed into direct connections by .NET defaults
- **`chatgpt_base_url` override.** A top-level `chatgpt_base_url` in `~/.codex/config.toml` (before the first `[section]`) is read and used as the API base, the same rule as the macOS fetcher; self-hosted gateway users no longer need extra configuration
- **Proactive token refresh.** When the access token's `exp` is within five minutes, it is refreshed before the request instead of waiting for a 401; the old refresh-once-and-retry on 401 stays. Tokens without an `exp` claim fall back to an eight-day age cap

## The flyout empty state: real errors, not a false "not configured"

When a configured provider fails to fetch, the panel now shows "fetch failed: <reason>", matching the macOS menu's `<Provider>: error` warning row; the "not signed in / not configured" guidance appears only when credentials are genuinely missing. Before, a network hiccup read as "you have not logged in yet" — and the debugging started in the wrong direction.

## Known boundaries (beta)

- The Windows artifact is a self-contained zip; unzip and run. No installer yet
- The auto-update channel (`/v1/app-update`) still points at the macOS artifacts; the Windows side only checks and reminds for now
- The macOS stable release remains v1.37.0 and is untouched by this one; `releases/latest` keeps pointing at v1.37.0
