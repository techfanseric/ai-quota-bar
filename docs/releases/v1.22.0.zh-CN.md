# v1.22.0 — 更清楚的菜单栏图标与准确的 GLM 状态

本次包含 v1.21.0 以来的全部改动，macOS 构建号 48。

## 小尺寸也能分清状态

- 菜单栏中心改为双向扇形：上方亮表示余量，下方亮表示透支，只有中心点亮表示节奏正常。未知节奏保持灰色，避免被误认为正常。
- 中心覆盖面积增大，顶部开口扩大到 104°，服务商字母略微上移；C / K / M / G 始终可见，小尺寸下不再与环端头挤在一起。
- 外环继续显示所选周期的剩余额度。黄色表示低额度；获取失败、数据不可用或 Codex 网络不通时显示红色横杠，有最后已知额度时保留该数值的外环。
- 分档与连续节奏模式继续可用。自检演示透支、正常与余量；活跃任务光带沿外环运动，避开顶部字母，悬停时继续显示节奏和动画。
- 修复最终菜单栏图片被系统模板化后丢失警告颜色的问题，并为自检与断网脉冲生成完整动画帧。浅色、深色及屏幕倍率变化会重新生成图标；遵循系统“减少动态效果”设置。
- 修正任务光带在顶部缺口处跳接的问题：按完整圆周运动，在字母开口处遮挡；30 fps、16 段平滑渐变，外环不再整体淡化。
- 每帧同时携带原生 1× / 2× 图像，跨屏显示不放大低分辨率缓存；位置对齐像素，按真实时间播放并保留刷新前后的运动相位。
- 修复 GLM 外环和中心节奏未跟随所选周周期的问题；5h 缺少重置时间时，按最近五小时的实际采样绘制曲线并正确归为短周期，不虚构重置时间或节奏。
- GLM 个人网页凭证可读取独立的可用重置次数与最近到期时间；只读展示，过期次数不计入额度，不执行兑换，查询失败不影响常规额度。

## 统一应用和网站图形

- 启动图标采用 A 标识与同一套扇形语言；警告弹窗、移动仪表盘主屏幕图标、官网品牌图标、favicon 和首页动态演示同步更新。
- 中英文设置说明及 README 同步解释余量、透支、警告和不可用状态。

## 团队网页细节

- 简化团队页顶部区域，退出登录移入面板工具行，页脚补充首页链接。
- 筛选与工具控件统一高度、圆角与背景；小时图列间距和轨道底色调整，空闲格保持透明，减少视觉粘连。
