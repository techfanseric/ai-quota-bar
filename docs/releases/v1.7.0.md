# AI Quota Bar v1.7.0

v1.7.0 的重点，是让菜单栏用更少的信息、更清楚地告诉你两件事：Codex 任务是否仍在工作，以及 OpenAI 当前应该换线路还是继续等待。

## 不打开菜单，也知道 Codex 还在工作

- 没有活跃任务时，剩余配额环保持 100% 实色，方便判断配额。
- 有任务运行时，基础环降为 60%，更容易看到沿剩余配额部分逆时针流动的能量波。
- 每个活跃任务对应一道波，最多显示五道；五个以上任务仍保持五道，避免 22pt 菜单栏图标变得拥挤。
- 波头最实，顺时针方向的长尾逐渐透明，既能看出运动方向，也不会变成突兀的圆点。
- 能量波绝不会进入已经消耗的配额段。
- 开启 macOS“减少动态效果”时，应用会保留静态任务提示。

## 左键配额面板恢复真正的 macOS 原生体验

- 左键面板重新使用系统 `NSMenu`，恢复原生半透明材质、阴影、圆角和菜单行为。
- 面板会根据当前菜单栏图标所在的显示器计算可用高度，减少外接屏、上下排列屏幕或不同菜单栏尺寸造成的错位。
- 左键与右键入口会在打开另一侧前主动收起，避免两个面板重叠。

## 右键控制中心更紧凑、更容易扫读

- 右键面板采用统一宽度、圆角和无三角箭头的边界，不再依赖不同系统环境下位置不稳定的 Popover 箭头。
- 自动恢复开关固定靠右，说明文字保持靠左。
- 线路改为单行布局，并用 `H2`、`VL`、`TLS`、`SS` 等标识快速区分协议。
- 线路和活跃连接列表保留最小浏览高度，数据较少时不会缩成几乎看不见的一行。
- 最近三次换线记录把“从哪里切到哪里”放在左侧；一小时内使用 `59m ago` 这类相对时间，较早记录显示具体时间。
- 没有换线记录时，历史区域自动收起，不浪费空间。

## 更快判断 OpenAI 连接是否健康

- 下载、上传和连接总数保持在图表上方，打开面板即可确认是否真的有数据流动。
- 连接年龄图例直接放进图表标题行，以 `New → Old` 表示从新连接到长连接的颜色变化。
- 活跃连接详情从 TCP 等协议字段开始，不再显示没有判断价值的未知进程占位文本。
- 监控仍然只读取 `openai.com` 与 `chatgpt.com` 的活跃连接，不会关闭连接或修改 Clash 配置。

## 安装说明

本版本要求 macOS 14 或更高版本，预编译 DMG 面向 Apple Silicon。

公开 DMG 使用 ad-hoc 签名，未经过 Apple 公证。首次打开时如被 Gatekeeper 拦截，请按住 Control 点击应用并选择“打开”，或前往“系统设置 → 隐私与安全性”允许打开。不要全局关闭 Gatekeeper。
