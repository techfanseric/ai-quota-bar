# 未发布 · 后台额度与常驻圆环（macOS）

关闭 Codex/ChatGPT 后仍会刷新 Codex 额度。若 Codex 配置了本机 Magpie 网关，AI Quota Bar 会优先读取 Magpie 的多账号额度报告。默认 Codex 环跟随当前账号，可选 Codex Pool 聚合全部已保存订阅；悬停显示每个账号最受限窗口、剩余比例和重置时间。Magpie 继续持有并刷新凭据；AIQuotaBar 只读取本机报告，不接触 Magpie 凭据。Magpie 不存在、未配置、停止或没有可用 Codex 卡片时，同一次刷新自动回退到已有的本机登录凭证 OAuth 优先链路。周期重置后的自动刷新也继续生效。已配置的 Kimi、GLM、MiniMax 数据源继续独立于对应桌面应用刷新。

在「设置 → 通用 → 菜单栏」选择「常驻显示」并点击「全选」，即可显示全部已配置且启用的服务商额度环。圆环优先于「跟随运行中的应用」过滤；左键菜单分区仍可按应用运行状态自动收起。暂停服务商或取消勾选仍会隐藏对应圆环，「工作感知」模式继续保留。

AI Quota Bar 本身仍须运行。凭证需有效，或完成支持的刷新/重新登录；错误不会被当作成功的额度读取。必要时仍可能运行已有的官方 CLI 凭证刷新或回退。由于 Magpie 通常只提供百分比、且不同套餐缺少可比的绝对容量，Pool 会平均各账号最受限的可读窗口；失败账号保留在悬停明细中，并保守按不可用计入分母。这些源码改动尚未包含在公开的 macOS v1.39.3 下载中，也没有新增 Windows 圆环设置。

各服务商差异见 [Magpie 源码方案对照](../research/magpie-quota-2026-11-12.md)。

## Codex 在用账号环

Magpie 的 `busy` 车道表示该账号有请求**正在厂商上游处理**。AI Quota Bar 将它与当前 trace seat 的账号身份合并：多个账号同时有上游请求时，Codex 一栏按账号显示多个 C 环，而不是额外叠加一个 Pool 总环。每个环显示该账号自己的额度（优先 5h），右上角活跃点表示正在使用；最多显示三个，其余在用账号列入悬停提示。顺序按 busy 数及账号名稳定排列。

多个 Codex 环时悬停逐环显示脱敏账号、额度与「正在使用」；单环保留原整条汇总悬停。左键菜单默认展开每个在用账号，包括有别名的账号；明确手动折叠仍优先。空闲或无法唯一归属时退回原单 Codex 环，归属不明会说明原因；暂时读失败保留最后可信账号与额度，并标记活动不可读。2 秒并发快照可能漏掉极短请求，不推断配额如何被调度。仅 macOS；没有新增 Windows 功能、远程网关访问、Magpie 凭据读取或活动上传。详见[调度调研与最终实现](../research/magpie-ring-scheduling-2026-11-17.md)。

## 任务流光准确性

Codex Hook 与日志按会话/回合对账：日志明确完成或取消时可结束漏收 Stop 的回合；Hook 已结束时不再被滞后的日志重新点亮。迟到的工具事件不会复活已结束回合，旧终态不会覆盖更新的工作；已知子会话归入主任务，父任务结束但子任务仍工作时保留流光。空白读取不推断为任务结束。

关闭睡眠保护只停止电源保护，不再丢弃 Hook 活动。ZCode、MiniMax、Claude Code 每轮检测结果一次合并，减少不同源分次更新引起的瞬时计数变化。

流光进一步按模型归属驱动现有四个环，不再把 Codex 客户端中的所有模型都算进 Codex 环。Codex 配置使用本机 Magpie 时，读取其既有本地 concurrency/trace 元数据，按当前实际尝试（含回退）统计执行中的模型请求；悬停显示具体模型和数量。直接运行的模型按本地回合元数据归属，未知路由别名不猜测。相同工作不会按任务与网关请求重复计数；网关请求之间的工具空档可能没有流光，完整任务的电源保护继续独立判断。仅发现配置中的 loopback 地址，不读取 Magpie 凭据或连接远程网关；元数据不上传。其他客户端的新鲜度检测仍有固有限制；Windows 未移植此次改动。见[口径、设计与验证](../task-activity-reconciliation.md)。公开版本和下载保持不变。
## 额度周期重置通知

每个已登记的本机额度窗口都能单独提示重置。既有周期边界刷新成功后，AI Quota Bar 会按账号/模型窗口发送一条去重 macOS 通知；无论上个周期是否用完都会提醒。正文总结上个周期用量与刷新后的新额度；若服务商仍显示为 0，会说明服务端重置可能延迟。通知遵循 macOS 授权与专注模式，账号名复用菜单脱敏设置，可在「设置 → 用量与团队 → 刷新」关闭。Magpie 的合成 Codex Pool 环不单独提醒，避免同一账号重置同时触发池/账号两条消息。AI Quota Bar 本身仍须运行；事件只在该服务商刷新成功后发送，不会把失败请求伪装成已恢复。
