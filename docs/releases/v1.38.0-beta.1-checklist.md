No changelog sync belongs in this release.
- **Windows curl against pages.dev fails TLS with `CRYPT_E_REVOCATION_OFFLINE` (exit 35) even though the network path is fine.** This machine's curl uses schannel, which insists on checking certificate revocation; the revocation endpoints are unreachable from here and the handshake dies before HTTP. Direct and via the Clash proxy (`http://127.0.0.1:7897`) it failed identically, which was the clue it was not a block. `curl --ssl-no-revoke` fixes it and plain direct IPv4 then works — no proxy needed for pages.dev at all. Add `--ssl-no-revoke` before concluding a Cloudflare property is unreachable from Windows.
- Network notes carried over from the release itself: direct `uploads.github.com` connections were reset during asset upload and had to go through the Clash proxy (`https_proxy=http://127.0.0.1:7897`, with `curl -4`), while `api.github.com` and `github.com` stayed directly reachable — confirmed again here (`github.com` 200 direct, and the 302 above came back without a proxy).
