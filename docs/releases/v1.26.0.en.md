# v1.26.0 — Menus follow your running apps

macOS build 54.

## Follow running apps

- Settings → Display adds a "Follow running apps" toggle (off by default). When enabled, the menu bar and left-click menu only show a provider while its desktop app is open: ChatGPT (Codex), ZCode (GLM), Kimi, or MiniMax Code.
- Providers appear and disappear automatically as apps launch and quit — no manual toggling. When no provider app is running, the menu bar keeps a placeholder so the status item stays clickable.
- If the left-click menu ends up fully hidden, a placeholder card explains why and offers a one-click switch back to showing all providers.

## Scope

Display-layer only: background quota refresh, data sources, account handling, and the mobile dashboard are unchanged. Provider pause, ordering, and per-item hiding settings keep working as before.

Requires macOS 14+; the DMG targets Apple Silicon and keeps the ad-hoc signature without Apple notarization.
