# AI Quota Bar v1.17.0

本次发布汇总 **v1.16.0 发布以来的全部改动**：从只看共享账号额度，扩展到本机 Codex 消耗与历史账号统计，并整合菜单、设置、云服务、运营后台和产品官网。

## Codex 本机用量与历史

- 从本机 Codex 的 sessions / archived_sessions 日志增量统计 Tokens、有效用量记录、缓存命中率与 API 等价值估算成本；支持今天按小时、7 天 / 30 天按天查看趋势。
- 展示输入、输出、缓存读写、模型分布、解析异常和价格覆盖情况。SQLite 持久化解析缓存与待上传队列，重启后继续处理，避免每次重扫全部历史。
- 对重复快照、归档副本、续页、分叉继承及累计值回退进行去重或异常处理；缺失父会话时暂缓统计，不猜测缺失用量。
- 优先使用日志中的账号信息，缺失时参考连续的本机登录观测；无法确认归属的历史单独保留为“账号未知”，不会全部归到当前登录账号。
- 支持导入带生效日期的模型单价。未知价格保留“未定价”，不伪装成零成本；估算并非供应商账单，记录数也不等于全部 HTTP 请求数。

## 菜单与设置

- Codex 供应商置顶，本机统计与额度信息集中在同一组；左键菜单聚焦当前 Codex 账号，去掉历史账号选择器，历史账号在设置中查看。
- 保留历史趋势，支持切换 Tokens / 用量记录 / 缓存命中率 / 成本并悬停查看时段数据；交互控件使用统一的中性色。
- 新增统一“显示”设置，将菜单显隐、手机模型选择和图表样式整合为账号 / 模型矩阵，减少重复设置。
- 账号总开关保留各模型的选择；手机维持 1–2 项限制；隐藏不影响采集、历史、告警或同步，暂不可用模型的已有选择仍保留。

## 成员与设备用量上报

- 新增独立的成员 / 设备绑定和用量上报开关，设备凭据保存在钥匙串；后台支持设备凭据签发、轮换和撤销。
- 支持按成员、设备、账号及时间范围查看统计；同一事件重复上传不重复计数，跨成员归属冲突隔离处理。
- 持久化补传、网络失败退避和绑定切换保护；历史用量是否归属、补传由用户明确选择。
- **当前仍需要管理员配置设备绑定。自助创建团队、一次性加入码和邀请加入流程尚未发布。**

## 云服务与运营后台

- 默认云端入口迁移到 `https://ai-quota-bar.pages.dev`，现有额度历史和用量数据保留；云端独立于旧部署资源运行。
- 新增 `/admin` 运营后台，支持独立管理员登录、匿名安装设备数、日 / 周 / 月活、7 / 30 / 90 天趋势及 App / macOS 版本分布。
- 匿名运营统计默认关闭，可在“设置 → 通用 → 隐私”开启或停止并删除本机统计；不采集 Codex 邮箱、对话内容或用量成本。
- 启动或打开菜单 / 设置计为活跃，后台心跳不计入日活。匿名安装数不等于真实用户数，也不包含旧版本和未开启统计的设备。

## 官网与手机看板修复

- 官网新增产品介绍和可交互的菜单、用量、显示设置及连接监控局部复现，全部用前端绘制，不使用截图。
- 手机演示直接复用 App 的前端组件，以示例数据展示任务、配额、线路、连接及保护状态；演示不会读取访问者的 App 数据。
- 重新梳理跨周期趋势、共享账号下的本机消耗、任务保护和连接诊断等核心功能，完善桌面和窄屏布局。
- 修复手机看板状态条条目数量变化时的渲染异常，避免额度 / 保护信息更新导致后续线路和连接区域空白。

## 下载与升级

下载 `AIQuotaBar.dmg`，将 App 拖入“应用程序”替换旧版。系统要求 macOS 14+，发布制品为 Apple Silicon（arm64），版本 1.17.0（build 35）。原有设置和本地历史保留；首次读取大量 Codex 历史可能需要数分钟。

公开 DMG 延续 ad-hoc 签名，未经过 Apple 公证。如首次打开被 macOS 拦截，可在“系统设置 → 隐私与安全性”按系统提示允许。升级后读取原钥匙串凭据可能需要再次授权。

更新检查仍采用现有的定期检查 / 系统通知与设置中的手动检查，下载跳转到 GitHub Release；本次没有引入自动安装器或左键菜单更新横幅。
