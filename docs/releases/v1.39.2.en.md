# v1.39.2 — Dim restores on local input by default

macOS 1.39.2 (build 85). Windows remains its separate v1.38.6-beta.1 prerelease and does not yet include per-display Dim.

- Renames the compact Dim option to **Restore on input** and enables it by default when no prior choice exists.
- Built-in trackpad/keyboard and Bluetooth mouse/keyboard movement, clicks, scrolling and key presses restore the saved brightness. Modifier keys are included.
- Keyboard detection requires macOS Accessibility permission. Pointer activity still restores without that permission.
- Turning the option off keeps the existing manual paths: click Restore or hold the menu-bar icon's right button.
- An explicitly saved enabled or disabled choice continues to win after an upgrade.

No display values, provider credentials or input contents are uploaded. The activity listener only triggers restoration and does not store keys or pointer data.

Install the PKG to replace the app in Applications. Requires macOS 14+ on Apple Silicon. The app is ad-hoc signed; the installer is unsigned and not Apple-notarized.
