# v1.28.0 — AI 任务保护覆盖全部四家供应商

macOS build 56。

## AI 任务保护扩展到 GLM 与 MiniMax

- 「AI 任务保护」此前只在 Codex 和 Kimi 任务期间阻止休眠；现在 **GLM 与 MiniMax 的本机编程任务同样参与保护**，四家供应商的任务计数、保护弹窗与手机看板任务列表全部合并展示。
- 新增三个只读、被动的本机检测器（不读取任何消息内容）：
  - **GLM（ZCode）**：读取 ZCode 桌面版与 CLI 共用的会话数据库，交互式会话保持更新即视为工作中；
  - **MiniMax CLI**：读取 `~/.minimax/v2/sessions` 各会话 `manifest.json` 的更新时间；
  - **Claude Code 桥接**：通过自定义端点在 Claude Code 里跑的 GLM / MiniMax 任务，按转录文件中响应模型的名称自动归属到对应供应商（其他模型，例如官方 Anthropic 端点，不会误触发）。
- 检测统一以「会话约 2 分钟内有更新」为工作信号，配合原有 5 分钟收尾宽限期；任务结束或 App 退出时立即释放全部断言的行为不变。
- 供应商是否纳入保护仍按本地实际存在判定：GLM 需要 Keychain 凭证或装有 ZCode；MiniMax 需要 Keychain 凭证或存在 MiniMax CLI 会话目录。
- 菜单状态行会随本地可检测的供应商动态列出（例如"已就绪 · 正在等待 Codex、Kimi、GLM 与 MiniMax 任务"）；系统电源断言名称改为中性的"AI task is working"。

说明：MiniMax CLI 检测基于会话清单的更新时间，任务计数的边界仍在持续校准中。

要求 macOS 14+；DMG 面向 Apple Silicon，沿用 ad-hoc 签名，未经过 Apple 公证。
