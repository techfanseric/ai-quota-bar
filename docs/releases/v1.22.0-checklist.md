# v1.22.0 release checklist

User instruction: after accepting the installed app, release **all changes since the previous release**, including the website, Chinese and English changelogs, and repository READMEs. Do not publish before acceptance.

Baseline: `v1.21.0` (tag fetched locally on 2026-09-20). Current post-tag commits are `392a5f6` (already published v1.21.0 localized notes) and `a1daed7` (team-page UI refinements); the icon redesign is currently in the working tree. Re-run `git log v1.21.0..HEAD` and inspect the full working-tree diff when publishing, because further acceptance fixes may follow.

Final release bodies: `v1.22.0.zh-CN.md`, `v1.22.0.en.md`. Existing public `cloudflare/content/releases.json` deliberately contains published releases only.

After acceptance:

1. Audit the full diff since the baseline, including team-page refinements and further fixes. Finalize a new version/build; rename and finalize both draft bodies, removing draft wording.
2. Refresh both README release summaries and their version links. Verify website Chinese/English hero version, download labels, release summary, screenshots and animated icons against the final application.
3. Run relevant tests and build/sign/package the final DMG. Verify installed binary and icon assets match that build.
4. Commit and push all intended changes; publish a new GitHub tag/release with the DMG and complete notes since v1.21.0.
5. Run `npm run sync:releases` under `cloudflare`, populate the new entry's `name_zh`, `name_en`, `body_zh`, `body_en` from the finalized drafts, and run `npm run build:pages`. Verify both `/changelog` and `/en/changelog`, homepage/download links, and historical release entries.
6. Deploy the production website using the repository's Pages deployment command, verify the live Chinese and English pages and release download, and commit/push the synchronized release content as needed.

Do not present the acceptance build as a published release, or publish only the most recent icon adjustment while omitting other post-v1.21.0 work.

Acceptance received on 2026-09-20. Version 1.22.0 / build 48. Release-mode regression: 47 tests passed. Website checks and tests passed. DMG packaged from the accepted release executable with updated bundle metadata; no functional rebuild needed.
