# v1.39.5 — Kimi quota without opening the client

macOS 1.39.5 (build 88). Windows remains its separate v1.38.6-beta.1
prerelease and does not include this change.

## Desktop token renewal

The Kimi Desktop reader now renews an expired short-lived access token with the
refresh token already stored by Kimi's own desktop client. This keeps configured
Kimi quota refreshes working after Kimi.app quits instead of leaving a
persistent red failure ring.

The renewed token stays in memory, is scoped to one Kimi account and region,
and is dropped before it reaches its expiry boundary. Only the Kimi origin
recorded in the desktop token store is contacted.

## Credential boundary

AI Quota Bar does not rotate, overwrite, upload, log or share Kimi's refresh
token, and never writes to Kimi's token store, Keychain entry or cookie
databases. If Kimi rejects the refresh token itself, sign in again in Kimi.

## Scope

This release changes only the Kimi Desktop session read path. Codex, GLM,
MiniMax, display behavior, sync and task protection are unchanged. Requires
macOS 14+ on Apple Silicon. The app is ad-hoc signed; the installer is unsigned
and not Apple-notarized.
