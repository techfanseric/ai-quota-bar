# v1.39.4 — 轻量模式、Magpie 多账号圆环与周期重置通知

macOS 1.39.4（构建 87）。Windows 继续保持独立的 v1.38.6-beta.1 预发布版本，未包含本次改动。

## 一分钟轻量模式

默认开启「设置 → 通用 → 系统 → 轻量模式」。左右键面板、设置和警告窗口关闭满一分钟后，释放可重新创建的界面资源；一分钟内重新打开则取消回收。首次使用前也不提前加载隐藏面板。

菜单栏 ring 的额度、趋势、模型流光、悬停明细与提醒继续运行，后台额度刷新、任务保护、Dim、同步、上报和 LAN 看板不暂停。可见、最小化或带有 sheet 的窗口不会被释放。

已保存设置、账号及历史保留；设置页签与窗口位置在重建时恢复（受显示器布局约束）。未保存的临时输入可能清空。实际内存收益取决于已打开页面和系统缓存，不承诺固定 MB。

## 关闭服务商应用后仍刷新额度

Codex 现在可以在 Codex/ChatGPT 关闭的情况下，用已保存的登录凭证走 OAuth 优先链路刷新额度。配置了本机 Magpie 网关时，优先读取它的多账号额度报告；Magpie 不存在或异常时自动回退到原本的当前账号读取链路。AIQuotaBar 全程不接触 Magpie 凭据。

默认的 Codex 环跟随当前账号，也可选择 Codex Pool 汇总订阅。**每个有请求正在厂商上游处理的账号，现在都会各自显示一个 C 环**（最多三个），活动期间替换原来的单 Codex 环。账号环显示该账号自己的额度和活跃点，悬停按既有账号脱敏偏好说明身份。左键菜单默认展开全部在用账号（包括使用别名的账号），用户明确手动折叠仍然优先。空闲时回到原单环；账号归属不明或活动暂时不可读时会明确解释，不冒充空闲。

在「设置 → 通用 → 菜单栏」选择**常驻显示**并点击**全选**，即可让全部已配置且启用的额度环在对应应用关闭时依然保留。常驻圆环优先于「跟随运行中的应用」，左键分区仍可自动收起。AIQuotaBar 本身仍须运行。

## 按模型归属的流光

流光现按**模型所属服务商**归环，而不是按 Codex 客户端归环。配置了本机 Magpie 时，实际执行请求会驱动 Codex/Kimi/GLM/MiniMax 对应环：Codex 客户端经本机 Magpie 调用 MiniMax 就亮 MiniMax 环，调用 GLM 就亮 GLM 环。悬停显示具体模型名称和请求数量。

统计按实际路由含回退计算，不按客户端名称归属。直接运行的本地模型任务保留生命周期检测，同一工作不会按任务和请求重复相加。未知别名不猜测。工具执行空档可能没有网关流光，任务电源保护仍可继续。

## 额度周期重置通知

每个已登记的 5 小时／周／月窗口到期时，先刷新额度，再发送一条去重摘要，说明上个周期是否用完、新周期还剩多少；无论是否用完都会提醒。账号名沿用菜单脱敏设置。通知仍受 macOS 权限与专注模式影响，可在「设置 → 用量与团队 → 刷新」关闭。

## 任务生命周期对账

按回合对账 Codex Hook 与日志：终态信号优先于滞后副本，已结束或取消的任务会被清除，能确认归属的子会话合并为同一任务，减少重复计数。关闭睡眠保护后 Hook 活动仍继续统计。

顺带修正了一个真实缺陷：回合结束的宽限定时器可能提前触发，且触发后不会重新挂载自己，导致电源保护可能一直不释放。现在按剩余时间重新挂载并取消容差，提前触发变得无害。

## 隐私边界

供应商登录凭据不会上传。Magpie 报告只读取本机公开接口，不接触其凭据。轻量模式只影响本机界面资源的释放时机。Dim 桥接只接受调暗请求，不暴露恢复接口，且不存储按键或指针数据。

双击 PKG 覆盖安装到 Applications。需要 Apple Silicon、macOS 14+。应用使用 ad-hoc 签名，安装包未签名，未经 Apple 公证。
