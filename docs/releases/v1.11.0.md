# AI Quota Bar v1.11.0

本版本汇总 v1.10.0 之后的图表样式设置、云同步重试修复与 D1 读写优化。

## 按模型选择图表样式

- 在用量设置中，为每个模型选择自动、面积图或进度条。
- 设置保存在本机，重启后保留；切回自动会清除该模型的手动覆盖。
- Mac 菜单与 Mobile Dashboard 使用同一套偏好，并提供中英文文案。

## 云同步客户端

- 修复客户端错误被通用异常处理重新捕获、导致无效重试的问题。
- 遇到明确的 D1 每日读写配额错误时，停止同一轮重试；临时网络故障和普通服务端错误保留原有退避重试。
- 账号摘要仅在接口返回 404 时回退读取最新快照；空结果、格式错误或普通服务端错误不再触发额外读取。
- 正常刷新频率、上传内容与历史保留策略不变。

## 配套后端降读写

- 通过触发器维护小型最新快照指针表，避免最新数据查询扫描全部历史。
- 全局历史查询先按设备限量，再合并选取最新结果；过期清理使用已有设备/时间索引。
- 完全相同的快照上传不再重复写入样本或设备心跳。
- 默认云端已完成迁移与发布。自托管用户需要按 [cloudflare/README.md](../../cloudflare/README.md) 执行迁移并配置开关；单独更新 Mac App 不会升级自托管后端。

生产环境验证中，最新数据 SQL 读取 176 行、写入 0 行，API 返回 24 个样本。本地 20 万行基准的全扫描步数从 399,998 降到 838，约减少 99.79%；这是本地查询基准，不代表生产账单同比降幅。

已有的账号级 D1 当日用量不会因升级清零；配额耗尽时，历史查询仍可能受限，需要等待重置或另行调整配额。本版本不变更套餐。

## 安装说明

要求 macOS 14 或更高版本，预编译 DMG 面向 Apple Silicon。

公开 DMG 使用 ad-hoc 签名，未经过 Apple 公证。首次打开如被 Gatekeeper 拦截，请按住 Control 点击应用并选择“打开”，或前往“系统设置 → 隐私与安全性”允许打开。不要全局关闭 Gatekeeper。
