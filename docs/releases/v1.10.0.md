# AI Quota Bar v1.10.0

v1.10.0 重点解决紧凑菜单栏在任务动画期间的持续高 CPU，同时完善多 Provider、配额预测和 Clash 线路筛选体验。

## 紧凑菜单栏性能与视觉

- 活跃任务动画保持 15 FPS。
- 使用预渲染的完整多 Provider 帧和 `NSStatusBarButton.image` 专用路径，避免每帧重绘、快照整个自定义视图。
- 发布机器实测活跃动画 CPU 从约 54–62% 降至多数 8–10%。
- Retina 离屏绘制使用正确的 2× 坐标变换，圆环恢复原始点尺寸、间距与对齐。
- 悬停继续显示 Provider 首字母；悬停期间使用静态预渲染帧，不产生额外持续绘制。
- 对角 pace 分隔线与竖向小时/天状态使用一致的颜色。

## 多 Provider 与配额判断

- 工作感知选择可同时展示 Codex 与 Kimi 的独立圆环。
- Kimi 活跃任务纳入菜单栏工作状态与睡眠保护。
- 新增配额消耗预测，并完善 reserve / deficit 周期表达。

## Clash 线路筛选

- 已保存的线路筛选默认以只读摘要展示，避免打开面板后误编辑。
- 主动点击后进入编辑模式，可切换正则表达式并明确完成编辑。
- 中英文文案、关闭面板后的编辑状态复位及对应测试均已补齐。

## 安装说明

本版本要求 macOS 14 或更高版本，预编译 DMG 面向 Apple Silicon。

公开 DMG 使用 ad-hoc 签名，未经过 Apple 公证。首次打开时如被 Gatekeeper 拦截，请按住 Control 点击应用并选择“打开”，或前往“系统设置 → 隐私与安全性”允许打开。不要全局关闭 Gatekeeper。
