# v1.38.2 — Fix stalled brightness controls and improve key responsiveness

macOS bug-fix release, build 78.

- Fixes background display-service creation holding the brightness control queue when an external display is off, changes input, or becomes unresponsive. Discovery runs outside the control queue, reuses valid connections, and bounds the caller's wait for service creation.
- Background scans no longer appear as an active Dim session. Manual Restore remains available while Dim maintenance is in flight.
- Reuses short-lived hardware readings during repeated key presses, changes only gamma when the hardware value stays unchanged, and reduces repeated discovery, unnecessary writes, and per-key read-back verification.
- Releases the IORegistry root handle after each scan to avoid accumulating resources over long sessions.
- 77 related tests passed, covering service timeout isolation, connection reuse, repeated-key I/O counts, and manual restore during maintenance. The local fix was installed and the user confirmed brightness keys worked after renewing Accessibility access.

If brightness keys adjust only the built-in display after updating, toggle AI Quota Bar off and on in System Settings → Privacy & Security → Accessibility so the updated application can take over the keys.
