# AI Quota Bar v1.13.0

本版本汇总 v1.12.2 之后的周期结束对齐刷新、菜单面板图表修复、手机仪表盘按任务来源适配、云同步读取重试与合盖模式可观测性增强。

## 周期结束自动对齐刷新

- 5 小时窗 / 周窗的结束时间很少恰好落在 10 分钟轮询点上：现在任一周期结束后 15 秒会自动刷新一次，随后常规轮询从该时刻重新起算，新周期数据第一时间到位。
- 仅对当前可实际拉取的本地 provider 生效（如 Codex 未运行时其模型不参与排程），云端同步来的模型数据不触发该机制。

## 菜单面板图表修复

- 云端数据瞬时拉取失败时保留上次样本，曲线图不再突然消失。
- 曲线图无数据时不再保留固定高度的空白容器，面板高度随内容自适应收缩。
- 悬停历史周期的曲线预览按该周期自身用量着色；当前周期余量不足触发的橙色警示不再串到历史周期预览上。

## 手机仪表盘按任务来源适配

- 只有 Kimi 任务在跑时：Kimi 配额卡片自动前置，隐藏仅统计 OpenAI 域名的连接区块和代理路由区块，标题改为「Kimi 活动」。
- 仅 Codex 任务或混合任务时保持原有完整展示；无任务运行时全部区块照常展示。
- 快照 schema 升级至 v4，新增 `activeProviders` 字段，旧版快照兼容解析。

## 云同步读取自动重试

- 读取路径对超时、DNS 失败、TLS 中断、连接丢失等瞬态网络错误按指数退避自动重试，与写入路径行为对齐；4xx/5xx 服务端错误不可自愈，立即报错。
- 网络错误提示统一为明确的中文文案（如"请求超时：到同步服务器的链路不通，请检查代理是否覆盖该域名"）。

## 合盖模式可观测性

- App 与特权 helper 增加 OSLog 日志：租约获取 / 释放 / 过期、SleepDisabled 被外部工具清除后重新断言等关键事件均可在控制台检索（subsystem `com.techfanseric.aiquotabar` / `.sleep-helper`）。
- helper 租约清扫周期由 15 秒缩短为 5 秒，外部电源管理工具改写 `disablesleep` 造成的冲突窗口更短。

## 安装说明

要求 macOS 14 或更高版本，预编译 DMG 面向 Apple Silicon。

公开 DMG 使用 ad-hoc 签名，未经过 Apple 公证。首次打开如被 Gatekeeper 拦截，请按住 Control 点击应用并选择“打开”，或前往“系统设置 → 隐私与安全性”允许打开。不要全局关闭 Gatekeeper。
