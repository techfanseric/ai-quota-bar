# v1.38.2 — 修复亮度控制卡住，缩短快捷键响应

macOS 修复版，build 78。

- 修复外接屏关机、切换输入源等情况下，后台显示器服务创建卡住并占用亮度控制队列的问题。服务发现移到控制队列之外，复用有效连接，并限制服务创建的等待时间。
- 后台扫描不再被误显示为仍处于 Dim；Dim 保持任务执行期间，手动恢复按钮仍可操作。
- 连续亮度键调节复用短期亮度读数，硬件亮度不变时只更新 Gamma，减少重复枚举、无效写入及逐次读回确认，改善按键响应。
- 修复反复扫描显示器时遗漏释放 IORegistry 根句柄的问题，减少长时间运行后的资源累积。
- 77 项相关测试通过，包含服务超时隔离、连接复用、连续调节的读写次数，以及保持任务执行中的手动恢复。修复版已在本机安装，用户确认重新授权后亮度键正常。

若更新后亮度键只控制内置屏，请在「系统设置 → 隐私与安全性 → 辅助功能」中，将 AI Quota Bar 关闭后重新开启，让更新后的应用重新接管亮度键。
