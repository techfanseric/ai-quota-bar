# v1.38.1 — Fix external displays getting stuck dim after brightness keys

macOS bug-fix release, build 76.

- Fixes external displays remaining visually dim even after hardware brightness has increased. A reduced 15% gamma table is no longer treated as the full-brightness reference or an upper brightness limit.
- Handles incorrect gamma references saved by v1.38.0 while preserving relative channel values and curve shapes.
- Fixes brightness keys pressed during the initial Dim read/write: wait for Dim to finish, restore the previous brightness, then perform the keyboard adjustment.
- 72 related tests passed, including saved-reference recovery, repeated increases, and input during Dim transitions. Local gamma output was verified to recover to 100% on both external displays.

Brightness keys still follow the pointer; saved Dim targets and smart-restore preferences are unchanged. If brightness keys stop responding after updating, toggle AI Quota Bar off and on in System Settings → Privacy & Security → Accessibility.
