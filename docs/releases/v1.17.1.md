# AI Quota Bar v1.17.1 — 趋势、任务与更轻的菜单

汇总自 v1.17.0 发布以来的全部改动。macOS 14+，Apple Silicon，构建 39。

## 用量与首次使用

- Codex 本机用量改为固定近 30 天日历矩阵，下方展示今日小时小柱图；保留 Tokens、用量记录、缓存命中率、估算成本切换。
- 左键菜单标题缩短为“本机用量 / Local usage”；仍只统计当前登录账号，历史账号选择保留在设置页。
- 悬停沿用周期柱图的浮层样式，不再显示竖向选中线；未定价、零用量、日历空位及未来小时分别呈现。
- 新设备未添加供应商时显示连接引导和可选示例预览，不自动请求未配置的 Codex。示例只在视图内生成，不进入存储、上报或告警。
- 尚未生成 Codex 日志目录时视为正常空状态；实际读取故障继续报告。Codex 暂未运行时引导打开应用，保留历史查看入口。

## 凭据与更新

- 成员上报凭据迁入共享钥匙串字典，与供应商、云同步和看板访问凭据共用缓存；旧凭据兼容迁移。
- 缺失的旧条目缓存查询结果，拒绝访问和损坏数据不再触发后台重复读取；供应商设置的“连接帮助”提供显式重试。
- 左键菜单 Settings 与 Quit 之间增加低强调新版提示；设置同步展示更新状态、下载和日志链接。
- 发现的新版跨重启保留；并发检查去重，检查失败允许 15 分钟后重试，通知提交失败不记录为已提醒。
- 下载仍使用 DMG 手动替换安装，不宣称自动安装。

## 图标与官网

- App 图标采用菜单栏额度圆环和中央节奏指示的黑白灰设计。
- 官网采用中性灰白背景，数据图表保留有意义的状态颜色。
- 增加完整历史版本更新日志与搜索，并提供从 GitHub 同步发布说明的构建脚本。
- 增加按 App 绘制规则实现的自检、空闲、单任务、多任务图标演示，可暂停并尊重减少动态效果设置。
- 看板介绍扩展到同局域网可访问 Mac 的手机、平板、车机及其他电脑浏览器。

## 菜单与同步诊断

- 移除左键菜单的服务商快捷暂停入口；暂停与恢复仍在供应商设置中管理。
- 云端读取错误不再占据菜单空间；设置 → 同步显示当前状态，并增加本机同步日志入口。
- 日志保留最近 200 条读取/上传结果，连续相同结果合并计数，可清空；记录错误代码，不保存 Token、请求地址或响应正文。
- 仅启用云同步的新设备继续等待云端历史，不错误要求添加本机供应商。

## 更完整的官网与跨屏演示

- 首页同时呈现左右键面板，独立介绍任务睡眠保护、可选合盖工作、线路测速切换及活跃连接。
- 首页与更新日志统一使用 App 图标；圆环以真实菜单栏尺寸自动轮换自检、空闲、单任务和多任务，保留手动探索与暂停。
- 官网本机用量演示同步为 30 天矩阵和今日小时柱，移除旧时间范围切换与暂停入口。
- 浏览器看板同时展示横屏亮色与竖屏暗色，使用 App 的实际前端及独立示例数据。
- 大横屏限制字体继续放大，为额度、任务与连接数据留出更多空间；手机原有自适应保留。
- 仓库 About 补充官网链接与功能介绍。

## 安装与范围

- 下载 DMG 后将 App 替换到“应用程序”。公开版仍为 ad-hoc 签名，更新提示提供下载入口，不自动安装。
- 自助创建团队、邀请设备加入仍在规划中；本次不把已有的成员归属上报描述为完整自助团队系统。
