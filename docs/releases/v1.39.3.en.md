# v1.39.3 — Reset alerts: 24-hour window and smarter routes panel

macOS 1.39.3 (build 86). Windows remains its separate v1.38.6-beta.1 prerelease.

- The reset-alert panel now shows only the last 24 hours: the unread count, pinned signal and clock history share that window. Older announcements stay archived locally for 30 days for revision deduplication, but never appear in the UI.
- Each message gains a **Dismiss** action: it disappears from the panel immediately and the same revision cannot return on the next poll; a newer revision is still delivered normally.
- The right-click panel's OpenAI routes section now starts collapsed: it auto-expands only when OpenAI connectivity is unreachable and collapses again once reachable. "Follow running apps" now aligns only the connections section, so a manually expanded routes section is no longer folded back.
- When "Restore on input" lacks Accessibility permission, the Dim controls show an orange hint with an **Allow** button that opens the Accessibility pane in System Settings; pointer activity keeps restoring without that permission.

No display values, provider credentials or input contents are uploaded. The activity listener only triggers brightness restoration and does not store keys or pointer data. Reset alerts keep reading public feeds only and never send Codex credentials.

Install the PKG to replace the app in Applications. Requires macOS 14+ on Apple Silicon. The app is ad-hoc signed; the installer is unsigned and not Apple-notarized.
