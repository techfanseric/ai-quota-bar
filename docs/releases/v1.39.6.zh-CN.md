# v1.39.6 — Codex 账号折叠时显示节奏

macOS 1.39.6（构建 89）。Windows 继续保持独立的 v1.38.6-beta.1 预发布版本，未包含本次改动。

## 折叠行显示节奏

在左键菜单中折叠 Codex 账号后，账号名和剩余额度之间会显示使用节奏（盈余/透支），不必展开账号就能判断当前节奏能否坚持到重置。

节奏与剩余额度采用同一个额度周期：折叠行右侧的百分比对应哪个周期，节奏就描述哪个周期。有多个周期时，展开账号即可切换。

节奏只在所选周期有效且数据足够时显示：周期已过、云端数据超过新鲜度限制或样本不足时不显示，也不会借用别的周期的数值。透支时文字变红，其余情况为次要色。

宽度不够时先省略套餐名，再截断账号名；剩余额度和节奏保持完整。

## 影响范围

本次只调整 macOS 左键菜单中 Codex 账号折叠行的显示。Codex、Kimi、GLM、MiniMax 的额度读取、同步、提醒和任务保护均未改变，不新增凭据访问、网络请求或上传。需要 Apple Silicon、macOS 14+。应用使用 ad-hoc 签名，安装包未签名，未经 Apple 公证。
