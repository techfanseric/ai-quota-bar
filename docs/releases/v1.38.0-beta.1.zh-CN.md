# v1.38.0-beta.1 — Windows 版公开测试与 Codex 链路修复

Windows build 74，公开测试（prerelease）。这一版做两件事：**Windows 版第一次开放下载**——macOS 菜单栏应用用 C# / .NET 8 按原版功能规格逐模块重写为原生托盘应用；同时把 Codex 抓取链路在 Windows 上补齐到 macOS 的行为——遵循系统代理、读取 `~/.codex/config.toml` 的 `chatgpt_base_url` 覆盖、token 到期前主动刷新。Mac 稳定版仍是 v1.37.0，不受本版影响。

## Windows 版，第一次公开测试

左键托盘图标弹出配额面板（环形仪表、模型行、用量条沿用 Mac 版设计语言），右键是原生命令菜单。功能按 `docs/win-migration/analysis/` 的规格逐项迁移：

- **Codex**：读取 `~/.codex` 的 OAuth / PAT 登录与多账号池，5h / Weekly 双窗口配额；未登录时自动隐藏
- **GLM**：API key 是唯一必填项，cURL 导入为可选高级功能；**MiniMax**：在设置里填入 token 即接入
- **Kimi**：桌面 / 网页会话与 CLI `/status` 解析
- **Clash / Mihomo**：本地控制器自动发现、分组切换、延迟测试、连接概览与自动恢复
- **任务防睡眠**：任务运行时 `PowerCreateRequest` 防止休眠，带电量安全网
- **移动看板**：18765 端口只读 HTTP + SSE，复用原 PWA 资源
- **团队**：Cloudflare Worker 的建队 / 加入 / 用量上报 / 配额上传

凭据用 DPAPI（CurrentUser）加密存储在 `vault.bin`；支持开机静默自启、单实例保护、亮 / 暗 / 跟随系统主题、中英双语与文件日志。本机验证（Windows 10 19045）：529 项单元 / 集成测试全部通过，Clash 集成测试真实执行，看板与任务→防睡眠链路真机走通。

## Codex 抓取链路，对齐 macOS

三个修复，都是「Windows 版照搬了字面实现，却丢了 macOS 侧一直依赖的行为」：

- **遵循系统代理。** Codex 配额请求与 Clash 探测现在走系统代理——需要代理才能出去的网络，不再被 .NET 默认行为绕开直连
- **支持 `chatgpt_base_url` 覆盖。** `~/.codex/config.toml` 顶层的 `chatgpt_base_url`（首个 `[section]` 之前）会被读取并作为 API 基址，与 macOS fetcher 同一条规则；自建网关用户不必再改配置
- **token 到期前主动刷新。** access token 的 `exp` 在 5 分钟以内时先刷新再请求，不等 401 才补救；401 后刷新并重试一次的旧逻辑保留。token 不带 `exp` claim 时按 8 天年龄兜底刷新

## flyout 空态：报真错，不再误报「未配置」

已配置的供应商抓取失败时，面板现在显示「获取失败: <原因>」，对齐 macOS 菜单的 `<Provider>: error` 警示行；「未登录 / 未配置」的引导文案只在真正缺少凭据时出现。此前一次网络故障会被误读成「你还没登录」，排查方向从一开始就偏了。

## 已知边界（beta）

- Windows 制品是自包含 zip，解压即用；暂无安装器
- 自动更新通道（`/v1/app-update`）仍指向 macOS 制品，Windows 侧目前只做版本检查与提醒
- macOS 稳定版仍是 v1.37.0，不受本版影响；`releases/latest` 继续指向 v1.37.0
