# v1.39.1 · Keep quota rings visible during alerts

macOS 1.39.1 (build 84). Windows remains the separate v1.38.6-beta.1 prerelease.

- Unread Codex reset updates preserve all quota rings. A persistent yellow dot replaces C, and only the Codex unit alternates between yellow and normal colors every 0.75 seconds. Quota values continue updating; Reduce Motion holds the yellow frame. Dim remains visible. Task waves pause until all alerts are acknowledged. If hidden by display selection, Codex is temporarily appended.
- Adds optional Settings → General → Account display → Mask accounts in menus, off by default. Both menus mask names and emails (abcdefg@example.com → a****g@example.com), including tooltips, delete prompts and external-switch details. Renaming pauses while masked and action summaries omit identities. Settings pages are outside the scope; domains and some name characters remain visible.
- Masking changes presentation only: account identity, switching, collection and sync retain their original data. Mobile Dashboard masking stays independent. These two features are macOS-only.
- Adds explicit --test-reset-alert launch argument for an in-memory, clearly labeled local preview. It uses the real alert path and disappears when acknowledged or on restart, without changing real announcements.
- The bilingual website now demonstrates yellow-dot ring alerts and documents menu masking, platform limits and current downloads.

Install the PKG to replace the app in Applications. Requires macOS 14+ on Apple Silicon. The app uses ad-hoc signing; the installer is unsigned and not Apple-notarized. Public reset announcements are third-party reports, not confirmation that your personal quota reset. System notification presentation depends on macOS settings.
