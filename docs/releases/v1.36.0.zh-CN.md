# v1.36.0 — 最新的那次采样，来源写在图标里

macOS build 72。这一版的核心是一句话：**同一个账号有两份数据时，显示采样更晚的那次，并且说清楚它从哪来。**

## 本地和云端都有数据时，显示更新的那次

账号行以前只要本地有值就显示本地的，不管团队云端刚上传的是哪一次。于是会出现这种情况：有人刚在另一台 Mac 上刷新过，你这边看到的还是本机缓存的那个数——"明明有人刚用过"这件事，从界面上完全看不出来。

现在同一个账号、同一个窗口，两边都有数据时，**采样时间晚的那次胜出**。这正是采样时刻一直被记下来的意义；在此之前没有它，这个比较根本做不出来，"永远用本地"是唯一答案。

有一边缺时间时仍然本地优先（对方用的旧版本，或接口不返回时间戳）。**"没法比"不等于"云端更新"**——把一个可能是几天前的云端数字当作当前值显示，比永远用本地更难解释。

## Kimi / GLM / MiniMax 也带上了采样时间

这三家原本都写 `sampledAt: nil`。和上一版修掉的那个"时间显示成未来"是同一个疏漏，只是落在当时还没人盯的区块上。

它们的接口都不返回服务端时间戳，所以用**响应解析的那一刻**作为采样时间：每次响应取一次，行和它所属的 `UsageData` 共用同一个值，两边不会差出几毫秒。没有这一步，"取更新的那次"就只是 Codex 的功能，其他三家看起来会像坏了。

## 来源不再是新词，图标本来就在说

账号行原本是 `[图标] 标签 · 时间 · 百分比`，标签可能是 `本机` / `云端` / `最新` / `混合`。这一版撤掉了后两个——

它们只为了让来源可见，而每一个词都要读者先查一次才知道是什么意思。"混合"更糟：这个 app 里别处从没教过读者"混合"是什么，它没有任何可以依托的直觉。

图标本来就带着同样的信息：**没有图标 = 这台 Mac 自己的账号，云朵 = 团队云端，眼睛 = 按邮箱关注的账号**。所以行里只留图标和数字，解释搬进 tooltip——那里可以说一整句话：这个数来自哪、什么时候量的，以及两边都有数据时说明显示的是较新的那次（不写出来，用户会对着一个"和本机不一样"的数字以为出了 bug）。

本机账号仍然显示来源名（OAuth / Codex CLI）。那个不是生造词，是这台 Mac 实际在跑的凭据，去掉它是丢信息，不是去噪音。

## 不用展开就能看到剩余额度

账号头现在显示所选窗口的剩余百分比，读那个数不再需要先展开账号。

**选哪个窗口按账号记**：一个账号想看 5h、另一个想看 Weekly 是常态，一个全局值意味着来回切。只有一个窗口时不出现切换器——一个选项的按钮按下去什么也不会发生，而最常见的情况（只有 Weekly）头部本来就显示这个数；有两个窗口时，头部下方出现一个紧凑的切换器。

还没选过的时候回落到**当前正在跑的窗口**，这样跨过重置点后它会自己修正，而不是指着一个刚关上的窗口。

这个选择**不驱动菜单栏环**。那是两个不同的意图：环是常驻的显示偏好，这里是"这一行我现在想看什么"。

## 供应商标题不再用计数占位

原来 Codex 显示 `2/5`（还有几个账号是新鲜的），其他家显示 `2/2`（还有几个模型有额度）。两个不同的含义挤在同一个位置，而且都不是每天会问的问题——它们是排查用的。

现在显示**这一节最后一次刷新的时间**，加上**当前账号**的剩余额度。用当前账号而不是合计，是因为菜单栏环显示的就是当前账号那个数：同一个 app 在两个地方给出不同答案，比少显示一个数字更糟。没有本地 Codex 账号时就不显示那个百分比，而不是随便挑一个——随便挑会读起来像是有意选的。整节都是陈旧数据时照样显示时间：最新的时间本身就是旧的，而每一行都带着自己的时间。

## 超额时，悬停画一条水平参考线

图表里原本有一条"按这个速度匀速消耗，你现在应该在这儿"的虚线对角线，但超额量要沿着斜线去目测。现在从悬停点向右边缘画一条水平线，它和对角线的交点就是**这个窗口已经被提前用掉了多少**。

只在超额时出现。进度正常时同一条线会让人以为出了问题——而 `onTrack` 带非零差值仍然是正常状态，所以判断依据是阶段本身，不是差值符号（代码里 `UsagePace.deltaPercent` 是实际减预期、`currentIntervalPaceDeltaPercent` 是预期减实际，两处符号约定相反）。线用图表的强调色而不是固定的绿色，这样它留在"预测"这一族里，不会读成数据；曲线本身转橙或转红时它也跟着保持一致。

## 顺带修正

- 团队成员名常常是邮箱、常常超出可用宽度，现在**截断而不是缩字号**（缩了会让同一栏里各行字号不一致，远看像某个成员"特殊"）
- 菜单栏那一行的"整个团队"改成**"全部"**。原来的措辞放不下，而且把选中的成员名整个挤出可视区——那个名字正是这个控件存在的理由。它紧跟在「团队」按钮后面，读者知道它指的是团队。设置里的选择器保留完整说法（那里有宽度，也遵循"所有设备 / 所有账号"的前缀式样）
- 账号名为空的分组（GLM、MiniMax，没有本地账号名时）**不再画账号头**。原本渲染成 `Local | 未知账号`：来源词区块标题里已经有了，"未知账号"只是把"没有名字"这件事又说了一遍。零信息，一行噪音。Kimi 没有账号名时同样处理
- MiniMax 订阅到期日去掉前导零：`2027-04-05` → `27/4/05`。到期日只关心"哪一天"，而右边没有宽度容纳补零的四位年份

## 已知边界

- 合并要求两边都有采样时间。对方没升级时本地优先，这是刻意的保守选择
- 水平参考线按"阶段"而不是差值正负判断，两处 delta 的符号约定在本代码库里是相反的
- 本地 + 云端合并的行只渲染胜出的那一次，但会记住两边都参与过（`mergedSourceKinds`），tooltip 里能看出来
