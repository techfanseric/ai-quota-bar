# v1.39.2 — Dim 默认输入即恢复

macOS 1.39.2（构建 85）。Windows 继续保持独立的 v1.38.6-beta.1 预发布版本，尚未包含分屏 Dim。

- 右键面板中的 Dim 选项改名为「输入即恢复」；没有旧选择时默认开启。
- 内置触控板／键盘与蓝牙鼠标／键盘的移动、点击、滚动和按键都会恢复调暗前保存的亮度，修饰键也包含在内。
- 键盘检测需要 macOS 辅助功能权限；未授权时，触控板和鼠标活动仍可恢复。
- 关闭选项后保留现有手动方式：点击恢复按钮，或长按菜单栏图标右键。
- 升级时继续尊重已经明确保存的开启或关闭选择。

显示器数值、供应商凭据和输入内容都不会上传；活动监听只触发亮度恢复，不保存按键或指针数据。

双击 PKG 覆盖安装到 Applications。需要 Apple Silicon、macOS 14+。应用使用 ad-hoc 签名，安装包未签名，未经 Apple 公证。
