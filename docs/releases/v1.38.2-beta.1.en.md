# v1.38.2-beta.1 — Windows flyout countdown no longer goes negative

Windows prerelease, build 77, cut from the v1.38.1 code with Windows-side fixes only.

- Fixes the negative countdown in the tray flyout header: when a refresh is overdue because of slow or failing fetches, the header showed "next in about -17 minutes"; it now shows "refreshing any moment" while overdue, and keeps "next in about N minutes" when on schedule.
- Packaging fix: the previous `AIQuotaBar-win-x64.zip` was actually a tar stream with a zip extension that Windows 10 Explorer cannot extract; from this release on it is a real zip (same layout — a top-level `AIQuotaBar/` folder; unzip and run `AIQuotaBar.exe`).

## Verification

- All 529 tests pass on Windows 10 19045.
- Verified on a 200%-scaled display: the flyout renders without scaling artifacts — title row, chart axes, usage bars and footer links all aligned; the window is 360 DIP wide, hugging the right edge above the taskbar.

Everything else matches v1.38.1; macOS is unaffected, `releases/latest` keeps pointing at v1.38.1, and this prerelease stays out of the changelog feed.
