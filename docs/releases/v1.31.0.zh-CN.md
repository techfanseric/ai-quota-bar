# v1.31.0 — 左键菜单用量卡片支持团队视角

macOS build 60。

## 菜单里的用量卡片可以切到团队视角了

- 左键菜单的 Codex 用量卡片新增「本机 / 团队」切换（存在团队连接时出现）：本机视图仍读取本地扫描；团队视图读取服务端聚合的当月用量与近 24 小时分时。
- 团队视图自带成员选择器：默认「整个团队」，也可下拉切换到单个成员，查看他/她的当月热力图与 24 小时分布。
- 团队视角不要求本机登录 Codex——没有本地 Codex 登录时卡片依然可用，只读成员上报的「共享本机用量」；尚无上报时显示空态提示。
- 服务端聚合的变化远慢于菜单的每分钟重绘，因此一次拉取结果复用五分钟；重新打开菜单、切换成员或团队会立即刷新。成员离开团队后选择自动回退到「整个团队」，断开团队连接则回到本机视图。
- 拉取前的空态也保持「近 24h」标题，与服务端固定返回 24 小时分时一致，避免布局跳动。

要求 macOS 14+；DMG 面向 Apple Silicon，沿用 ad-hoc 签名，未经过 Apple 公证。
