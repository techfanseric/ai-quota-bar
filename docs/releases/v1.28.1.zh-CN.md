# v1.28.1 — 任务检测可靠性修复，启动不再冻结

macOS build 57。

## MiniMax 任务检测修复

- 检测信号从会话 `manifest.json`（实测会落后实际写入数分钟）改为**会话目录内文件的活动时间**：转录仍在写，任务就计为进行中。
- 新增对**桌面版 MiniMax Code 后台任务**（`~/.minimax/background-tasks`）的检测——此前这类任务完全不可见，是"任务在跑却计为 0"的主要原因。

## Kimi 任务检测修复

- 旧检测依赖的 `session_index.jsonl`（新版运行时已停止维护）和按进程工作目录匹配的门控在新版 Kimi 桌面端下全部失效，导致任务时有时无。
- 现在从桌面 agent 的 `conversation-context-usage.json` 读取每个会话自带的 `updatedAt`，更新中的会话计为进行中。
- CLI 的 wire 转录仍受支持：turn 开启且文件仍在更新才算活跃，进程被杀后自动衰减，不会永久误保护。

## 启动不再被钥匙串阻塞

- 重签名安装后的首次钥匙串授权弹窗，此前会让整个应用冻结在启动线上（无状态栏、感知不到任何应用退出/启动）。
- 凭证库预加载改为异步：状态栏立即出现、全部功能即刻可用；弹窗回答后自动校正已配置缓存并刷新一次。

要求 macOS 14+；DMG 面向 Apple Silicon，沿用 ad-hoc 签名，未经过 Apple 公证。
