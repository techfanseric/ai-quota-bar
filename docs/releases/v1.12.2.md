# AI Quota Bar v1.12.2

本版本汇总 v1.11.0 之后的图表时间轴规范统一、本地样本缓存、历史周期预览、云端状态诊断与睡眠保护加固。

## 图表时间轴按自然边界对齐

- 多日窗口的分隔线按本地 0:00 对齐（原为周期起点 + 24 小时），一眼看出是哪一天。
- 单日窗口（如 5 小时）的分隔线按本地自然整点对齐（原为起点 + N 小时）。
- 悬停时只给完整落在窗口内的时段标注：多日窗口在当天正午居中显示 `MM/dd`，单日窗口在该小时半点居中显示 `3PM` 式标签；窗口两端不完整的时段不标注。
- 跨天进度条（周窗口）悬停时同样只标注完整自然日，居中于当天正午。

## 本地样本缓存

- 消耗样本改为合并式写入并保留 90 天，重装新版或重启后历史曲线不再丢失。
- 每个模型的样本量设上限并自动裁剪最旧数据，缓存体积可控。

## 历史周期悬停预览

- 悬停跨周期 utilization 柱图中的任意历史周期，曲线图即时切换为该周期的消耗曲线预览；移开即恢复当前周期。

## 云端同步状态诊断

- 云同步错误分类提示：网络超时、DNS/连接失败与 D1 配额耗尽分别给出明确文案，不再笼统显示"请求超时"。
- 同步设置页新增 D1 当日用量状态行（读取行数 / 每日限额），按 50% / 80% 阈值显示绿 / 黄 / 红。
- 配套 Worker 新增 `/v1/d1-usage` 只读用量接口（Cloudflare GraphQL 分析数据源，5 分钟边缘缓存），默认云端已部署；自托管用户需要按 [cloudflare/README.md](../../cloudflare/README.md) 配置 `CF_API_TOKEN` 等开关，单独更新 Mac App 不会升级自托管后端。

## 睡眠保护加固

- 任务结束后保留电源断言和合盖租约 5 分钟宽限期，回合间隙和活动检测抖动不再导致任务中途睡眠。
- XPC 瞬时断连不再立即释放合盖租约，改为依赖租约自然过期。
- 发现内核 SleepDisabled 标志被外部清除（如其他工具或电源切换）时自动重新断言。
- 心跳租约按协商超时延长，屏保用户活动每 45 秒刷新。

## 安装说明

要求 macOS 14 或更高版本，预编译 DMG 面向 Apple Silicon。

公开 DMG 使用 ad-hoc 签名，未经过 Apple 公证。首次打开如被 Gatekeeper 拦截，请按住 Control 点击应用并选择“打开”，或前往“系统设置 → 隐私与安全性”允许打开。不要全局关闭 Gatekeeper。
