# v1.25.0 — 左键菜单供应商可排序，月度周期标签修正

macOS build 53。

## 左键菜单

- 设置 → 显示新增「菜单供应商顺序」：供应商按当前顺序排成一行，用箭头逐位调整。默认顺序为 Codex、Kimi、GLM、MiniMax；调回默认顺序会自动清除自定义设置，旧版本保存的偏好正常加载。
- 顺序只影响菜单展示，额度采集、历史、告警与同步不受影响。

## 月度周期标签

- Kimi 月度「Total usage」行的历史柱图此前标注为「Week cycles」，现改为「Monthly cycles」。手机看板快照新增明确的周期种类字段（short / weekly / monthly），没有该字段的旧快照回退到原有推断逻辑。

## 范围

本次仅为展示层调整。Kimi、Codex、MiniMax、GLM 的数据来源、刷新门槛与账号处理逻辑均未改变。

要求 macOS 14+；DMG 面向 Apple Silicon，沿用 ad-hoc 签名，未经过 Apple 公证。
