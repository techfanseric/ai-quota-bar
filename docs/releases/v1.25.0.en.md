# v1.25.0 — Reorderable menu providers, correct monthly cycle label

macOS build 53.

## Left-click menu

- Settings → Display gains a "Menu provider order" section: providers appear as pills in their current order and can be moved one position at a time with arrow buttons. The default order is Codex, Kimi, GLM, MiniMax; moving back to the default clears the custom setting automatically. Preferences stored by older versions load unchanged.
- The order only affects display; quota collection, history, alerts and sync are untouched.

## Monthly cycle label

- Kimi's monthly "Total usage" row labeled its history bars "Week cycles"; it now reads "Monthly cycles". The mobile dashboard snapshot carries an explicit cycle kind ("short" / "weekly" / "monthly"), and older snapshots without the field fall back to the previous inference.

## Scope

Display-only changes. Kimi, Codex, MiniMax and GLM data sources, refresh gating and account handling are unchanged.

Requires macOS 14+. The Apple Silicon DMG retains ad-hoc signing and is not Apple-notarized.
