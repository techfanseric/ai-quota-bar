- Public-impact change: the macOS left-click Codex menu shows pace in a
  collapsed account row, between the account name and the remaining
  percentage, using the same selected window as that percentage. The label
  appears only for a current window with enough data and respects the existing
  cloud freshness limit. No installation step, download format, supported
  platform or privacy-boundary change.

  Kimi source note keeps linking to its own v1.39.5 validation record.

  metadata is unchanged and Windows beta does not replace `releases/latest`.

## Actual limitations

- Pace compares the used percentage with a linear reference for the selected
  window; it is a local estimate, not a provider forecast, and is omitted when
  the window is not current or lacks data.
- The macOS installer is ad-hoc signed, unsigned and not Apple-notarized.
- The Windows build is not part of this release; v1.38.6-beta.1 remains a
  separate prerelease with its own feature set.
