# v1.39.4 publication record — 2026-11-19

## Scope and website impact

- Public-impact change: one-minute lightweight mode (on by default), Magpie-driven
  multi-account quota rings, per-account Codex rings for accounts with in-flight
  requests, model-attributed activity lights, quota cycle-reset notifications, and
  the turn-based task reconciliation that backs them. No installation step,
  download format, supported platform or privacy-boundary change.
- Website update required. The bilingual home pages (hero release note, feature
  sections, FAQ and download metadata), the bilingual README/user guidance, the
  platform capability matrix and this release's bilingual notes are synchronized in
  this delivery.
- Windows remains the independent v1.38.6-beta.1 prerelease; Windows download
  metadata is unchanged and Windows beta does not replace `releases/latest`.
- Privacy boundaries unchanged: provider credentials stay local, only the local
  Magpie report is read, the lightweight mode only releases local interface
  resources, and the Dim bridge accepts brightness requests only.
- Publication authorized: the final commit, tag, assets, GitHub Release and Pages
  deployment verification are recorded below.

## Actual limitations

- The lightweight mode reports the retained and released native settings
  footprint per run rather than promising a fixed MB saving, because the real
  figure depends on the visited pages and system caching.
- Magpie reports percentages, and different plans lack comparable absolute
  capacity, so the Codex Pool aggregate averages each account's most
  constrained readable window. Failing accounts stay visible in the hover
  details and are conservatively counted as unavailable in the denominator.
- The macOS installer is ad-hoc signed, unsigned and not Apple-notarized.
- The Windows build is not part of this release; v1.38.6-beta.1 remains a
  separate prerelease with its own feature set.
