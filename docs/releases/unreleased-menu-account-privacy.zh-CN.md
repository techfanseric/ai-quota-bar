# 菜单账号脱敏（未发布，仅 macOS）

- 在「设置 → 通用 → 账号显示」新增「菜单账号脱敏」开关，默认关闭，选择会保存并即时应用。
- 左键额度菜单及右键 Codex 当前账号、备份名称和邮箱保留首尾字符，例如 `abcdefg@example.com` 显示为 `a****g@example.com`。单字符完全隐藏，双字符仅保留首字符；邮箱域名保留。
- 外部账号切换提示、悬停详情、删除确认和旧备份名称同步脱敏。账号操作状态改用通用文字，脱敏时暂停菜单内重命名，避免编辑框显示原始账号。
- 仅改变菜单显示，不改变账号身份、登录、分组、切换、采集或同步；手机看板有独立脱敏开关。设置页面不在本开关的覆盖范围内。
- Windows 尚未实现。当前 Mac v1.39.0 和 Windows v1.38.6-beta.1 公开下载保持原样；新功能已打包为本机测试构建 1.39.0（83），尚未公开发布。
