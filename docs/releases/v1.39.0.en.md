# v1.39.0 — Codex reset inbox and visible Dim state

For macOS 14+ on Apple Silicon. Windows remains the separate v1.38.6-beta.1 prerelease; these Mac features are not included in its existing ZIP.

## Public reset announcements with explicit acknowledgement

- The left-click menu follows codex-reset.com and codex-resets.com, preserving source links and distinguishing clues, previews, reported resets and Banked messages. A third-party announcement does not prove your individual account has reset.
- Unread messages replace the quota indicator with an orange bell, alternating brightness every 0.75 seconds or staying steady with Reduce Motion. New messages attempt a system notification; reminders repeat every five minutes until explicitly acknowledged.
- Opening a source or dismissing a notification does not mark messages read. Acknowledge one or all messages without closing the panel. Source links close the panel before opening a browser. An old notification cannot acknowledge later message revisions.
- History is always accessible and covers 30 days. Older unread entries remain until acknowledged, and the latest explicit preview, reported reset or Banked signal stays visible after acknowledgement without restarting reminders. State survives app restarts.
- Three feeds are polled independently. A failed source does not clear unread entries; meaningful announcement updates become unread again. System notifications depend on permission and Focus settings; menu-bar alerts continue independently. Test-alert controls are absent from the release.

## Visible Dim state during remote access

Step Away Dim adds a steady screen-and-moon badge to the menu bar, including during quota animations and reset alerts. Restoring the displays removes the badge. This is a state indicator without a quota progress ring.

## Menu and website updates

The menu material, rounded outline and window shadow stay aligned as content resizes in the same panel. Bilingual website and user guides now explain recent brightness controls, account sources, credential mirroring and Windows differences. Windows coverage includes installation and upgrades, Codex CLI fallback, Watch, Codex task protection, mobile monitoring and actual limitations. The changelog labels the independent Windows beta while Mac stable and Windows versions remain separate.

Repository rules require assessing website impact before pushing, synchronized bilingual content and version checks, and production verification after deployment. See the release checklist for actual test, packaging, checksum and publication results.

Distribution retains ad-hoc app signing, without Developer ID installer signing or Apple notarization.
