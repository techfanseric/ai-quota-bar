# v1.22.0 — Clearer menu-bar icons and accurate GLM status

All changes since v1.21.0. macOS build 48.

## States that remain readable at menu-bar size

- The center now uses two opposing fans: upper segments mean reserve, lower segments mean deficit, and a lit center dot means on pace. Unknown pace stays muted instead of appearing healthy.
- Larger center shapes, a 104° top opening, and a slightly raised provider letter improve separation at small sizes. C / K / M / G stay visible at all times.
- The outer arc continues to show remaining quota for the selected window. Yellow means low quota. Failed or unavailable data and Codex connectivity outages use a red dash, retaining the last known quota arc when available.
- Staged and continuous pace modes remain available. Self-test demonstrates deficit, on pace, and reserve. Active-task waves follow the open ring without crossing the provider letter; hover retains pace and motion.
- Final status-button images preserve warning colors instead of losing them to macOS template rendering. Self-test and offline pulses now have complete animation sequences. Icons regenerate for appearance and backing-scale changes and respect Reduce Motion.
- Task waves now follow a physical circle and are masked through the provider opening instead of jumping between endpoints. Playback uses 30 fps and 16 gradient segments; the quota ring is no longer dimmed during tasks.
- Every frame includes native 1× and 2× images, avoiding low-resolution upscaling across displays. Pixel-aligned placement and elapsed-time playback preserve sharpness and motion phase across refreshes.
- Fix GLM ring and pace indicators ignoring the selected weekly window. When the 5h API omits reset metadata, chart actual samples from the last five hours and classify it as a short window without inventing reset times or pace.
- Show available GLM personal reset allowances and their next expiry when using supported web credentials. This is read-only, excludes expired allowances, never redeems resets, and keeps optional lookup failures separate from quota.

## One visual family across the app and website

- The launch icon uses A and the same fan geometry. Warning panels, mobile dashboard home-screen icons, website branding, favicon, and live homepage demos are updated together.
- Settings descriptions and both READMEs explain reserve, deficit, warning, and unavailable states.

## Team dashboard refinements

- A simpler header places sign-out in the panel toolbar and adds a homepage link in the footer.
- Filter and toolbar controls share consistent heights, corner radii, and backgrounds. Hourly-chart spacing and track backgrounds are refined, with transparent idle cells to prevent visual merging.
