# macOS v1.39.7 (90) release verification

Website update required. This release ships Magic Keyboard brightness recovery on two supported Bluetooth models, the Dim permission request, and optional Magpie ring cache refresh with current-account fallback. Both home pages, downloads, FAQ, capability matrix, READMEs, release notes and the Pages Worker fallback are updated. Windows remains the independent v1.38.6-beta.1 prerelease.

Before the detached Swift tests, the companion app quit and launch call sites were checked. The default closures are inert, the production singleton opts in, and tests inject inert closures or counters. Keyboard mapping is injected into the production brightness controller. The compatibility check reads HID properties and does not record keystrokes.

End-to-end validation requires a signed-in macOS session, the app running with Accessibility granted, pointer brightness enabled, and a supported display under the pointer. Login startup is required for automatic recovery after reboot. Local existing mappings take precedence; this release targets the Bluetooth keyboard services with product IDs 0x029A and 0x0267.
