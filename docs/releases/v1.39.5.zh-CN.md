# v1.39.5 — 不打开 Kimi 也能读取额度

macOS 1.39.5（构建 88）。Windows 继续保持独立的 v1.38.6-beta.1 预发布版本，未包含本次改动。

## 桌面登录续期

Kimi 桌面读取器现在会用 Kimi 桌面客户端已保存的 refresh token，在内存中续期过期的短期 access token。这样 Kimi.app 退出后，已配置的 Kimi 额度刷新仍能继续，不再因为遗留 token 过期而常驻红色。

续期得到的 token 只保存在内存中，并按账号和区域隔离；临近过期边界会先丢弃。请求只会发往桌面 token store 中已记录的 Kimi origin。

## 凭证边界

AI Quota Bar 不轮换、改写、上传、记录或共享 Kimi 的 refresh token，也不写入 Kimi 的 token store、钥匙串条目或 Cookie 数据库。如果 Kimi 拒绝 refresh token 本身，仍需要在 Kimi 中重新登录。

## 影响范围

本次只调整 Kimi 桌面会话读取路径。Codex、GLM、MiniMax、显示行为、同步和任务保护均未改变。需要 Apple Silicon、macOS 14+。应用使用 ad-hoc 签名，安装包未签名，未经 Apple 公证。
