# v1.29.0 — Task waves end instantly, idle load drops sharply

macOS build 58.

## GLM/ZCode tasks now end on time

- A live experiment established that ZCode's `turn_usage` ledger only INSERTs a row once a turn reaches a terminal state (`completed`/`error`/`cancelled`, including user cancellation) — no running row is observable while a turn executes.
- Detection is now hybrid: start and running still come from `time_updated` freshness, and every poll consumes newly-landed terminal rows by rowid cursor, dropping the session from the active set immediately.
- End/cancel latency falls from up to ~120 seconds to a single poll cycle (2–3 s), and cancellation becomes visible for the first time. A turn continued right after a cancel is protected by the terminal-timestamp gate and is not mistakenly dropped.
- If the table schema drifts, detection falls back to freshness-only behavior, identical to the previous release.

## Idle-footprint fixes (two pinned cores)

- Kimi CLI: wire transcripts are parsed incrementally, resuming from the last consumed newline. Idle machines previously re-read hundreds of historical transcripts in full on every poll, pinning a core at 100%.
- MiniMax: each `bg_*` directory's mtime is prefetched with the listing call, and the probe files are read with a raw `stat` — `FileManager` previously raised and caught an ObjC exception per missing file, which across thousands of accumulated task folders saturated a core on its own.

## Task wave: chase-queue layout (new default)

- A second task-wave layout, chase queue, becomes the default: all waves line up single-file along the visible arc with constant-bright head beads, so every wave stays visible and countable at any task count.
- The previous full-orbit behavior remains selectable in settings as evenly spaced.
- Ambient animation (task wave, offline pulse) re-renders at 12 fps instead of 30 fps: every tick costs a full CPU-side bitmap render, so the slower cadence more than halves the idle render workload while slow motion stays visually smooth. With Reduce Motion the queue parks in a static pose on the visible arc.

## Admin console (website)

- `/admin` gains "Open dashboard": the platform admin can enter any team's dashboard without its password — including device-only teams that predate `usage_teams`.
- Rotating the invite code of a device-only team now returns 404 instead of silently handing out a code that was never persisted.

Requires macOS 14+; the DMG targets Apple Silicon and keeps the ad-hoc signature without Apple notarization.
