# v1.38.6-beta.1 — Windows 托盘可见性、设置排版与 Codex 关注

适用于 64 位 Windows 10+ 的独立预发布版。已合入 macOS v1.38.5 源码，macOS 稳定版保持 v1.38.5。

- 托盘两种模式增加深色底和浅色边框；详细模式分两行显示服务商和额度，完整信息保留在悬停提示中。
- 设置页按内容自动计算行高，长标签支持换行；设置、路由和连接页明确使用 96 DPI 布局基准；控制中心重新读取主显示器 DPI。尚未完成所有缩放比例和多屏组合的目视验收。
- 「Settings → Providers」新增 Codex 分享与关注操作：选择本机分享账号、添加/移除关注、校验邮箱和拦截重复、手动刷新、查看状态、全部额度窗口、云端发布时间和被查看次数。
- Watch 修改即时保存并请求同步，不再只等待十分钟轮询；Cancel 不撤销 Watch 修改。旧版分享与关注邮箱配置会保留。
- 分享默认关闭。知道已分享邮箱的其他用户可以读取其额度；服务商凭据不会上传。账号池中尚未获取额度的账号需要先登录并刷新。

下载 `AIQuotaBar-win-x64.zip`，解压运行 `AIQuotaBar/AIQuotaBar.exe`。内含 .NET 8，无需额外安装运行时；目前没有安装器或代码签名。覆盖程序前先退出旧进程，保留 `%APPDATA%\AIQuotaBar` 中的设置和凭据保险库。

验证：Windows 全套 543 项、官网 124 项测试通过，官网语法检查通过；macOS 测试未在 Windows 重跑。本次未移植服务商多账号登录管理、数据源选择和 macOS 凭据镜像。

本版本标记为预发布，不替换 macOS 稳定版 `releases/latest`。官网正式版更新日志按现有规则不收录预发布，Windows 下载卡片直接链接到本版本。
