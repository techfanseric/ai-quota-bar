# v1.38.6-beta.1 — Windows tray visibility, settings layout and Codex Watch

Windows-only prerelease for x64 Windows 10+. Includes the merged macOS v1.38.5 source; the macOS stable release remains v1.38.5.

- Both tray modes now have a dark backing and light border. Detailed mode displays provider and quota on two lines, with full details in the tooltip.
- Settings rows size to their content and wrap long captions. Settings, Routes and Connections have an explicit 96 DPI layout baseline; the control center rechecks the primary monitor DPI. Full multi-monitor and scaling acceptance remains outstanding.
- Settings → Providers now includes Codex account sharing and watching: select local accounts to share, add/remove watched emails, reject invalid or duplicate addresses, refresh, and inspect status, all quota windows, publication time and read counts.
- Watch changes save immediately and request synchronization without waiting for the regular ten-minute poll. Cancel does not undo Watch edits. Existing sharing and watched-email settings are preserved.
- Sharing stays off by default. Anyone who knows a shared email can read its published quota. Provider credentials are never uploaded. Pool accounts without fetched local quota must be signed in and refreshed before publishing.

Download `AIQuotaBar-win-x64.zip`, extract it, and run `AIQuotaBar/AIQuotaBar.exe`. The package includes .NET 8; no installer or code signing is provided. Quit the running app before replacing its program files. Keep your `%APPDATA%\AIQuotaBar` settings and vault.

Verification: 543 Windows tests and 124 website tests passed; website syntax checks passed. macOS tests were not rerun on Windows. Account login management, provider data-source selection and the macOS credential mirror are not ported in this release.

The Windows release is marked prerelease and does not replace the macOS stable `releases/latest`. The website's stable changelog intentionally excludes prereleases; its Windows download cards link directly to this release.
