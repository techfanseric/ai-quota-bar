# v1.28.1 — Reliable task detection, launch no longer freezes

macOS build 57.

## MiniMax task detection fixed

- The working signal now comes from **file activity inside the session directory** instead of `manifest.json`, which measured minutes behind the live transcript — a working task no longer drops out of the count.
- **MiniMax Code desktop background tasks** (`~/.minimax/background-tasks`) are now detected; they were invisible before, which was the main cause of "tasks running but the count stays zero".

## Kimi task detection fixed

- The old signals — `session_index.jsonl` (no longer maintained by the new runtime) and the process working-directory gate — stopped matching entirely under the new Kimi desktop runtime, so tasks flickered in and out.
- Detection now reads each conversation's own `updatedAt` from the desktop agent's `conversation-context-usage.json`.
- CLI wire transcripts still count: a turn must be open **and** the file must be freshly touched, so a killed process decays instead of protecting forever.

## Launch no longer freezes behind the Keychain prompt

- The one-time Keychain authorization after a re-signed install used to freeze the whole app at launch — no status bar, and app quit/launch events went unnoticed.
- The credential-vault preload is now asynchronous: the status bar appears immediately with every feature working; once the dialog is answered, the configured cache is corrected and one refresh runs.

Requires macOS 14+; the DMG targets Apple Silicon and keeps the ad-hoc signature without Apple notarization.
