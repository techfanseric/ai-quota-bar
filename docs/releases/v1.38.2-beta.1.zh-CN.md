# v1.38.2-beta.1 — Windows 面板倒计时不再出现负数

Windows prerelease，build 77，基于 v1.38.1 的代码，只含 Windows 侧修复。

- 修复托盘面板头部的负数倒计时：刷新因抓取缓慢或失败而逾期时，头部会显示「下次约 -17 分钟后」这样的负数；现在逾期时改显示「即将刷新」，未逾期时仍显示「下次约 N 分钟后」。
- 发布制品修正：上一版的 `AIQuotaBar-win-x64.zip` 实际是改了扩展名的 tar 流，Windows 10 资源管理器无法解压；本版起是真正的 zip（目录布局不变，顶层 `AIQuotaBar/` 文件夹，解压运行 `AIQuotaBar.exe`）。

## 验证

- Windows 10 19045 本机 529 项测试全部通过。
- 在 200% 缩放的显示器上实测托盘面板：布局无缩放错乱——标题行、图表坐标轴、用量条与底部链接行对齐正常，窗口宽 360 DIP、贴右侧悬在任务栏上方。

其余功能与 v1.38.1 相同；macOS 稳定版不受影响，`releases/latest` 继续指向 v1.38.1，本 prerelease 不进入更新日志订阅源。
