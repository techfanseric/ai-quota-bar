# v1.32.0 — Step-away dimming, closed-lid dimming and an adaptive Clash panel

macOS build 61.

## Step away: dim every screen with one click

- The protection popover gains "Step away · dim all screens": every display is instantly covered by a black shade (screen-saver level windows) while the built-in backlight drops to zero and external monitors dim over DDC/CI; moving the mouse or pressing any key restores everything.
- Press and hold the right-click on the status bar icon for 0.6 seconds to dim directly; a quick right-click still opens the popover.
- Shade darkness is adjustable in Settings → General (60–100%, 90% translucent by default): below 100% is a pure overlay that never touches the backlight, and only full black performs real dimming.
- Keyboard restore uses a listen-only event tap behind the Accessibility permission and silently falls back to mouse-only restore when it is missing.
- On launch the app restores any dim state left behind by a previous crash or force-quit, so screens never stay dark.

## Automatic built-in display dimming while working with the lid closed

- While closed-lid protection is running (a task is keeping the Mac awake), the built-in display is held at minimum brightness without affecting external monitors; system auto-brightness recovery is continuously countered.
- The original built-in brightness is persisted and restored on the next launch after an abnormal exit.

## The Clash panel adapts to the screen height

- The right-click Clash panel switches from a fixed baseline height to the anchored screen's available height: on small screens it first compresses the account section (internally scrollable), then yields space from the connection list, and finally collapses the accounts to their header row — the connection list is no longer squeezed to death or clipped at the tail.
- Display changes and re-anchoring recompute the budget automatically.

## Detection accuracy

- Kimi desktop agents now use the conversation status ledger as the authoritative lifecycle source: tasks end immediately (no more lingering up to 120 seconds) and start lighting up instantly, with the heartbeat kept only as a crash fallback. The CLI silence window widens to 10 minutes so long tool calls no longer flicker out of the active set.
- Kimi Work (daimon) desktop runtime sessions are now detected and labeled "Kimi Work" in the task list.
- Codex hook turns gain a 10-minute TTL reaper: kill -9 or a lost Stop hook no longer leaves ghost tasks pinning the protection ring to "working" forever.
- Claude Code model attribution follows the newest assistant message in the transcript: switching a session back to the official model stops counting it toward GLM/MiniMax immediately.
- Switching or re-signing into a Codex account refreshes the current account in the left-click menu instantly instead of waiting up to 60 seconds.

## Admin console

- Account quota detail is rebuilt as an app-style provider → account → model-column hierarchy, one column per model side by side, with search, expand/collapse-all and reset view.
- Expanding an account lazily loads up to 168 hours of quota history; timestamps use UTC+8 in the Chinese UI (UTC in English).
- Charts now draw to the container's actual width with graceful narrow-column degradation; MiniMax and Z.ai provider logos are added.

## Local data

- The local usage database slims itself: cloud-confirmed events are dropped locally after 40 days (the charts read a ~35 day window), and the file is vacuumed when free pages exceed 64 MB; pending, rejected and local-only rows are never touched.
- Detection polling logs only on active-task count transitions, and the MiniMax detector skips stale background folders, cutting daily log volume and disk scanning noticeably.

Requires macOS 14+; the DMG targets Apple Silicon and keeps the ad-hoc signature without Apple notarization.
