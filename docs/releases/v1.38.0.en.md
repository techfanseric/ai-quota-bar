# v1.38.0 — Brightness keys follow the pointer, with per-display Dim targets

macOS stable release, build 75. Includes the display brightness changes from October 19, 2026. Windows remains on the separate v1.38.0-beta.1 prerelease.

## Control the display under the pointer

- Brightness keys adjust only the display under the pointer, including repeated presses while holding a key. Option + Shift provides fine adjustment.
- Built-in displays use native brightness. Supported external displays use DDC/CI hardware brightness, extending below the hardware minimum through gamma. The combined range follows MonitorControl's default mapping, with a 15% gamma output floor.
- These keys do not change saved Dim targets. During Dim or a settings preview, a brightness key first restores the previous levels, then adjusts the selected display.
- Settings → General includes a brightness key toggle and an Accessibility permission button. Quit MonitorControl when using this feature to avoid competing key and gamma controls.

## Per-display Dim targets and immediate preview

- Save a separate target for each display and read its current hardware brightness.
- Drag a slider to preview that display immediately. After releasing it, move the pointer or press any key to restore; leaving settings also restores. There is no fixed preview countdown.
- Smart restore beside the Dim button is off by default. With it off, click Restore or hold the right mouse button on the menu bar icon again to restore; with it on, input activity can restore automatically.
- No software overlay, monitor contrast changes, or RGB gain changes. Hardware brightness and original gamma tables are saved for restoration, including recovery after an interrupted session.

## Keep local dimming through UU remote connections

- Repairs gamma resets that previously made physical displays brighter when UU connected or disconnected while Dim still appeared active. Reconnected displays are matched by stable identity.
- Normal gamma brightness also recovers after resets. Entering Dim from an already reduced gamma level uses the original calibration, avoiding cumulative dimming.
- A short test on this setup confirmed that restoring local gamma dimming left the UU remote image unchanged. No UU settings were modified.

## Validation

68 related Debug tests passed. Small brightness adjustments and restoration were checked on the built-in display and two external displays. Release-mode test compilation is blocked by an existing menu bar test calling a Debug-only method; the release application builds successfully.
