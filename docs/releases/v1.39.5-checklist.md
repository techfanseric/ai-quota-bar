# v1.39.5 publication record — 2026-11-19

## Scope and website impact

- Public-impact change: Kimi Desktop quota refresh now renews an expired
  short-lived access token in memory with Kimi's existing refresh token when
  Kimi.app is closed. This fixes the persistent red Kimi failure ring.
- Website update required. Both localized home pages, localized README/user
  guidance, platform capability rows, release notes and Worker update fallback
  are synchronized. Download buttons point to the stable `latest` channel and
  display macOS v1.39.5.
- Windows is unchanged and remains the independent v1.38.6-beta.1 prerelease;
  it does not replace `releases/latest`.
- Privacy boundary: Kimi's refresh token is not rotated or written back; no
  Kimi token is logged or uploaded; the renewed access token is in-memory only
  and scoped by account and origin. No Magpie credential is touched.

## Actual limitations

- Renewal works only while Kimi's refresh token itself remains valid; if the
  server rejects it, the user must sign in again in Kimi.
- The macOS installer remains ad-hoc signed, unsigned and not Apple-notarized.
- The Windows build is not part of this release.
