来源：https://codexbar.app/logos/（Simple Icons 风格 SVG，v0 尺寸 24–100）。

- 文件名保持站点原名；`-dark` 后缀是白色单色版（深色背景用）。
- App 内通过 `ProviderLogo.assetName(for:)` 映射 UsageProvider：
  minimax → minimax.svg，kimi → kimi.svg，codex → codex-dark.svg，glm → zai-dark.svg（Z.ai）。
- 其余 logo 目前仅随包备用，供后续新增 provider 直接取用。
- 各 logo 版权归对应品牌所有，仅作识别用途。
