统计口径与隐私

成员用量来自每台 Mac 上报的本机 Codex 日志统计，与账号剩余额度分开。输入已含缓存读取，输出已含推理 token，不能再次相加；总量为输入 + 输出。有效用量记录不等于完整 HTTP 请求数。

本机消耗使用账号的 SHA-256 标识；额度快照包含账号显示名称（可能是邮箱），仅当前团队可见。事件只含时间、模型、token 数和不透明标识，不含对话、代码、文件路径或任何供应商凭据。成本为按配置单价的 API 等价估算，未配置价格的记录计入 token 但显示“未定价”。

同一事件跨设备只计一次；内容冲突的重复上报会被拒绝并保留在成员本地。移除设备只停止其后续上报，已入账的历史不会删除。
