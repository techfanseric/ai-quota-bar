01 / 历史不是附加项

这一轮的下降速度。
过去几轮的使用节奏。

实线留下额度变化，参考线帮助判断能否用到重置。下方每根小柱都是一个历史周期，悬停即可回看那一轮的曲线。

  • 当前周期

    5h 与 Weekly 分开看，剩余量、重置时间、盈余或透支同时呈现。

  • 跨周期回看

    不止“现在还剩多少”，还可以比较前几轮是否用足、何时消耗最快。

  • 提前安排

    节奏判断与低配额提醒，帮助你在额度见底前安排下一项工作。

macOS 的 Codex 额度查询支持 OAuth 与本机 CLI 回退；同账号刷新失败保留成功快照并标明错误，不把其他账号的旧值带入。

在右侧历史柱上悬停，或用键盘聚焦，回看不同周期。

02 / 共享账号，也看得清本机 v1.23.0

账号的额度。
这台 Mac 的消耗。

几个人共用一个 Codex 账号时，总额度解释不了每台电脑用了多少。本机用量从本地日志统计，让你单独查看自己的 Tokens、有效用量记录、缓存命中率和估算成本。

  • 本月 + 最近 24h

    本月日历与最近 24 小时矩阵并排，每格 5 分钟。成本有有效价格时才显示。

  • 跟随当前账号

    左键菜单不增加账号选择。切换过的账号，在设置里分别查看。

  • 有依据的归属

    无法确认账号的旧记录单独保留；成本按配置单价估算，不冒充账单。

账号池 / 切换不需要重新登录 v1.30.0

换一个 Codex 账号。
不用再登录一遍。

右键面板新增「Codex 账号」分区：当前账号与账号池里的所有备份一目了然，点「切换」就是一次原子改名换位——没有登录弹窗，也不用扫码。

  • 登录新账号

    把当前凭据存入账号池，自动打开 ChatGPT 让你登录一次；此后新账号永远只有一键之遥。

  • 绝不代替你退出

    ChatGPT/Codex 正在运行时，切换请求会挂起等你退出，几秒内自动接力完成；文件搬动前的最后一刻还会再查一次运行状态。

  • 配额跟着账号走

    每个账号都记录上次获取到的 5h 与 Weekly 剩余百分比和重置时间，切换之前先看一眼。

  • 凭据守护 macOS · v1.38.5

    在 ~/.codex 之外为本机见过的账号保留受限权限副本；外部网关改写登录态时显示切换提示。镜像只跟随保存，不自动恢复或替你切号。

账号池就地管理：重命名、删除（进废纸篓）、一键收编以前手动改名的旧备份。API Key 模式的 auth 文件不会被自动处理。 常驻优化减少重复历史扫描与菜单栏重绘，保留刷新与动画节奏；尚未验证空闲 CPU 低于 1%。

账号关注 / macOS + Windows

只填邮箱。
跨平台关注 Codex 额度。

分享方勾选账号，关注方填写邮箱，就能在自己的 Mac 或 Windows 上查看已发布额度。不用建团队，不用在关注的机器上登录同一 Codex 账号。

  • 独立于团队

    关注与团队是两条独立通道，可以分别使用；macOS 同账号多来源取采样较新的一次并保留来源标记。

  • 先看是否新鲜

    显示额度窗口、重置时刻与更新时间；未分享、过期和网络失败分别提示，旧快照不冒充实时结果。

  • 明确公开范围

    分享默认关闭。开启后，任何知道该邮箱的人都可查询已分享的额度；上传额度元数据，不上传供应商登录凭据。

03 / 共享账号，按人算清楚 v1.23.0

额度是大家的。
谁用了多少，看得见。

几个人合用一个 Codex 账号，额度就成了黑箱：剩多少看得见，谁用掉的说不清。组建团队后，每台 Mac 的本机用量按成员自动汇总，账号额度也实时共享——谁在用、用了多少，不用再互相问。

  • 建团队

    在 App「设置 → 用量与团队」直接创建；管理密码保存在钥匙串，邀请码分享给成员。

  • 邀成员

    成员在自己的 Mac 上填写邀请码、名字和成员口令加入；同一人多台 Mac，用同一成员口令。

  • 自动汇总

    各设备上报本机用量，App 内按成员、设备与账号多维拆分查看；用量与账号额度两项共享可分别暂停。

  • 菜单里的团队视角 v1.31.0

    左键菜单的用量卡片可切到团队：整个团队或单个成员的当月与近 24 小时用量，不要求本机登录 Codex。

所有成员点击「查看团队」免输入密码直达只读面板；管理员点击「管理团队」直达邀请与设备管理。不同团队的数据相互隔离，额度历史保留 90 天。

谁用了多少 · 设置与网页同款

同一套用量图表，
App 和网页都有。

「谁用了多少」在 App「设置 → 用量与团队」和 /team 网页面板里是同一套图表：按成员、设备、账号与日期拆分，月历加最近 24 小时 5 分钟粒度，悬停查看精确数值，定价覆盖一目了然。

  • 多维拆分

    按成员、设备、账号与指定日期查看；上方范围切换控制整体对比。

  • 5 分钟粒度

    本月日历与最近 24 小时矩阵并排；未上报的时段如实留空，不冒充零消耗。

  • 定价覆盖

    有有效价格才计成本；未完整定价如实标注，不冒充账单。

右键 / 工作的另一半

不止看额度。
也照顾正在跑的任务。

左键看趋势，右键打开控制面板。任务睡眠保护、合盖工作、线路切换与连接监控，在一个紧凑的面板里串起来。

  • 按任务唤醒

    Codex、Kimi、MiniMax、GLM 任务活跃时保持 Mac 唤醒，任务结束后释放保护。屏幕常亮和阻止屏保可单独选择。

  • 合盖继续

    需要收起屏幕时，可开启合盖工作。默认关闭；首次启用需安装系统辅助组件，并受电量、温度、心跳与最长运行时间约束。

  • 网络在手边

    测速、过滤和切换 OpenAI 线路，查看连接历史与即时流量。自动恢复可按需开启。

同步状态和详细日志放在设置里，菜单专注当下工作。

macOS / v1.38–1.39

离开时调暗。
远程也看得出 Dim 已开启。

每块屏幕独立保存 Dim 目标亮度；开启后菜单栏显示屏幕与月亮标记，远程查看菜单栏也能确认本地屏幕仍处于调暗状态。

  • 按屏幕调暗

    拖动滑块可即时预览，输入活动或离开设置后恢复预览。智能还原默认关闭；Dim 可手动恢复，长按菜单栏图标右键也可恢复。

  • 亮度键跟着指针

    内置屏使用系统亮度，支持 DDC/CI 的外接屏优先调整硬件亮度，最低后用 Gamma 继续调暗。Option + Shift 可精细调节。

  • 恢复原来的画面

    保存并恢复调暗前的硬件亮度与色表；针对远程连接重置 Gamma、外接屏响应停滞和按键连续调节作过修复。

仅 macOS；Windows 尚无分屏 Dim、亮度键与 Dim 状态标记。

macOS / v1.39.0

重置有新线索。
明确确认前，持续提醒。

独立读取 codex-reset.com 与 codex-resets.com 的公开消息，区分未确认线索、重置预告、站点报告已重置与 Banked 消息。来源报告不能证明你的账号已重置。

  • 保留各站来源

    正常情况下每分钟检查，网络失败后退避；不跨站合并。预告变为确认或内容改变，会作为新版本提醒。

  • 未读不会静默消失

    未读保存在本机，重启后继续；菜单栏提醒铃闪烁，每 5 分钟再次尝试系统通知，直到逐条或全部确认。

  • 由你明确确认

    打开菜单、原文或通知正文不会清除未读。只有明确的确认操作结束对应提醒；减少动态效果时图标常亮。

系统通知受 macOS 授权、专注模式与通知设置影响；菜单栏提醒仍保留。Windows 尚未提供。

托盘里的
AI 工作仪表。

面向 64 位 Windows 10+ 的原生 .NET 8 WinForms 应用。左键打开额度控制中心，右键打开命令菜单；当前公测已包含额度曲线、周期历史、本机用量、关注账号、Codex 任务保护与局域网看板。

    Codex 读取本地登录，OAuth 失败时回退本机 CLI；仅有 Weekly 的账号也能显示。Kimi 尝试 API key、桌面会话和 CLI；GLM 填 API key，MiniMax 填 token。

    按账号与额度窗口查看剩余量、重置时间、节奏、曲线和历史周期；Codex 分区包含本机用量。刷新失败保留同账号本次运行的成功数据并标明错误。

    Settings → Providers 支持逐账号分享、添加/移除邮箱、手动刷新、状态与被查看记录；Mac 与 Windows 可以互相关注。分享默认关闭。

    Codex 活跃时阻止系统睡眠，任务结束后释放；普通防睡眠无需管理员。可选合盖模式修改电源方案，需要管理员权限，结束后恢复。

  • 线路与看板

    Clash / Mihomo 控制器发现、线路筛选/测速/切换、自动恢复与连接监控；启用 Mobile Dashboard 后可在同局域网浏览器查看状态，支持配对码和账号掩码。

    本机统计 Codex tokens、缓存命中率和估算成本；已有团队客户端与上报通道。Windows 设置尚未提供与 Mac 对齐的原生建队/加入流程或账号归属切分。

  • 原生托盘

    文字与圆环两种模式，深色底与浅色边框增强对比；设置行高自适应。支持开机自启、单实例与 DPAPI 凭据保险库；全套多屏缩放目视验收尚未完成。

WINDOWS / 安装、更新与边界

解压即可运行。
升级保留本机设置。

下载独立 Windows 公测 ZIP，包内自带 .NET 8 运行时，无需另装 .NET。当前没有安装器和代码签名，安全提示中请核对来源后再运行。

  • 开始使用

    解压后运行 AIQuotaBar/AIQuotaBar.exe；托盘可能折叠在任务栏的「隐藏图标」区域。先完成 Codex CLI 登录，或在 Providers 配置其他服务商。

  • 更新与数据

    先退出旧程序，再替换程序目录并重新启动。保留 %APPDATA%\AIQuotaBar 中的设置、历史和保险库；保险库用当前 Windows 用户的 DPAPI 加密。

  • 排查连接

    OAuth 使用系统代理与证书验证，CLI 使用自己的网络配置；两条路径共同的代理/证书故障不会由回退自动修好。日志位于 %LOCALAPPDATA%\AIQuotaBar\app.log。

第一次安装怎么开始？

下载安装包并双击，macOS 会把它装进「应用程序」并拉起 app——替换前会先退出正在运行的旧版，装完自动把安装包本身删掉。公开版安装包没有开发者签名、也没有经过 Apple 公证；若 macOS 提示无法验证开发者，可 Control 点击安装包选「打开」，或在系统「隐私与安全性」里点「仍要打开」。

Windows 版怎么安装与更新？

下载 v1.38.6-beta.1 x64 ZIP，解压运行 AIQuotaBar/AIQuotaBar.exe。自带 .NET 8，面向 64 位 Windows 10+，暂无安装器或代码签名。升级前退出旧程序，保留 %APPDATA%\AIQuotaBar，再替换程序目录。更新检查只提醒并打开发布页；完整步骤与权限说明见Windows 安装指引。

本机消耗和账号配额有什么不同？

账号配额反映供应商侧的总量；本机消耗来自这台 Mac 上的 Codex 日志。有效用量记录不等同于底层所有 HTTP 请求。

几个人共用一个账号，怎么汇总各自的使用？

在 App 的「设置 → 用量与团队」创建团队，成员用邀请码和名字加入，各自的本机用量会按人自动汇总。完整流程与面板介绍见上方「共享账号」一节；管理员在 /team 查看明细、轮换邀请码或撤销设备，不同团队的数据相互隔离。

我的数据会自动上传吗？

本机用量可在本地统计。加入团队后，用量上报和账号额度共享可分别暂停；未加入团队不上传团队数据。「账号关注」是独立公开通道：主动开启分享后，知道邮箱的人可查询已分享额度，不需要团队。供应商登录凭据不会上传；macOS 凭据镜像仅保存在本机。匿名运营统计另有独立开关。本页只用演示数据，不读取你的账号或日志。

切换 Codex 账号，历史如何归属？

新版优先使用日志中的账号信息；缺少时参考连续的本机登录观测。无法可靠归属的旧记录保持“未知”，不会自动算到当前账号。成本按配置单价估算，并非供应商账单。
