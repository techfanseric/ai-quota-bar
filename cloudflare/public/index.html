01 / 历史不是附加项

这一轮的下降速度。
过去几轮的使用节奏。

实线留下额度变化，参考线帮助判断能否用到重置。下方每根小柱都是一个历史周期，悬停即可回看那一轮的曲线。

  • 当前周期

    5h 与 Weekly 分开看，剩余量、重置时间、盈余或透支同时呈现。

  • 跨周期回看

    不止“现在还剩多少”，还可以比较前几轮是否用足、何时消耗最快。

  • 提前安排

    节奏判断与低配额提醒，帮助你在额度见底前安排下一项工作。

在右侧历史柱上悬停，或用键盘聚焦，回看不同周期。

02 / 共享账号，也看得清本机 v1.17.0

账号的额度。
这台 Mac 的消耗。

几个人共用一个 Codex 账号时，总额度解释不了每台电脑用了多少。本机用量从本地日志统计，让你单独查看自己的 Tokens、有效用量记录、缓存命中率和估算成本。

  • 小时 / 天

    今天按小时，7 天或 30 天按天，四种指标都能回看趋势。

  • 跟随当前账号

    左键菜单不增加账号选择。切换过的账号，在设置里分别查看。

  • 有依据的归属

    无法确认账号的旧记录单独保留；成本按配置单价估算，不冒充账单。

第一次安装怎么开始？

下载 DMG，将 App 拖入“应用程序”，打开后在设置中连接你的供应商账号。公开版使用 ad-hoc 签名；若 macOS 提示无法验证，可按住 Control 点击 App，选择“打开”，或在系统“隐私与安全性”中允许。

本机消耗和账号配额有什么不同？

账号配额反映供应商侧的总量；本机消耗来自这台 Mac 上的 Codex 日志。多人共用账号时，新版可按成员和设备上报，让各自的消耗清晰可见。自助创建团队与邀请加入仍在规划中。有效用量记录不等同于底层所有 HTTP 请求。

我的数据会自动上传吗？

Codex 本机用量可以在本地统计。成员与设备上报需要开启并配置连接；额度云同步与匿名运营统计各有独立开关，默认关闭。页面中的数据均为演示数据，不会读取你的账号、日志或 App 设置。

切换 Codex 账号，历史如何归属？

新版优先使用日志中的账号信息；缺少时参考连续的本机登录观测。无法可靠归属的旧记录保持“未知”，不会自动算到当前账号。成本按配置单价估算，并非供应商账单。
